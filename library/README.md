# Library

Shapes and drawings anyone can use in their work, free of charge and without
credit: everything here is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Scissor shows this folder in its **Library** panel. The app builds a search
index from it when it is deployed; nothing here is edited by hand.

## Adding an asset

1. Put an `.svg` in a folder (folders can nest: `animals/birds/owl.svg`).
2. Give it a `<title>` - the name shown in the panel - and a `<desc>` with
   comma-separated search words: `<desc>owl, bird, night, wise</desc>`.
3. Keep it plain vector: paths and shapes, no scripts, no linked files, no
   embedded fonts or images.
4. Only add work you made yourself and are happy to give away under CC0.
