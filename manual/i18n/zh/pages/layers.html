图层面板是文档的地图：每个图层、编组和对象都在一个列表中，按它们在页面上的叠放顺序排列。用它来显示和隐藏、锁定、重命名、重新排序和选择对象，并一眼看出任意对象位于哪个图层。

下文中的快捷键以 macOS 形式书写。在 Windows 和 Linux 上，请将 ⌘ 视为 Ctrl，⌥ 视为 Alt，⇧ 视为 Shift。

图层面板

从窗口 › 图层（F7）打开它。列表的顶层是你的各个图层，每个图层的内容嵌套在其下方：编组、路径、文字、图像和像素图层，以可展开和折叠的树形结构显示。容器（图层或编组）的行左侧带有一个小三角形；单击它可以折叠或展开该容器。由于可以折叠你当前没有处理的部分，层级很深的文档也能保持清晰易读。

面板底部有两个按钮。创建新图层会在当前图层的正上方添加一个空图层，并将新图层设为当前图层。删除所选项会删除所选的任何内容；文档始终至少保留一个图层，因此无法用这种方式删除最后剩下的图层。要重命名任意图层、编组或对象，请在列表中双击其名称，输入新名称，然后按 Enter。为复杂文档的各部分命名，是让它保持易于浏览的最快方法。

图层与编组

图层是文档的顶层容器。它们的作用是将图稿中互不相关的部分分开：背景放在一个图层上，主体绘图放在另一个图层上，标签放在第三个图层上。由于图层位于树的根部，隐藏、锁定或重新排序图层，就能一步移动其中的所有内容。

编组是位于图层（或另一个编组）内部的较小容器，随图稿一起移动。编组用于将同一事物的各个部分（例如标志或图标的各个部件）绑在一起，使它们作为一个整体移动、缩放和叠放。编组在面板中也有自己的三角形用于展开和折叠，与图层完全相同。

图层和编组在一个重要方面表现相同：每个都可以显示或隐藏、锁定或解锁，并且每个都可以带有自己的不透明度和混合模式，作用于其中的所有内容。区别在于角色。图层组织整个文档；编组则绑定单个对象。

编组和取消编组

选择两个或更多对象，然后选择对象 › 编组（⌘G）将它们收集到一个编组中。对象 › 取消编组（⇧⌘G）会将所选编组中的对象重新取出。编组可以嵌套，因此由编组组成的编组也没问题；每按一次 ⇧⌘G 剥离一层。当你发现自己一遍又一遍地选择同样几个对象时，就该使用编组了。

堆叠顺序：前与后

对象从后往前绘制，因此在重叠处，靠前的对象会遮住其后方的对象。面板直接显示这一顺序：最上面的行是最前面的对象，最下面的行是最靠后的对象。重新排序对象会改变谁遮住谁。

最快的重新排序方法是拖动：抓住一行，在列表中把它放到更高或更低的位置，以在堆叠中移动它；或者把它放到某个图层或编组上，将对象移入其中。拖动也是将所选对象移到其他图层的方法——无需剪切和粘贴。

显示和隐藏

单击任意行上的眼睛即可隐藏该图层、编组或对象；再次单击即可恢复。隐藏的行不参与绘制、打印或导出，因此隐藏是在不删除的情况下把东西挪开的安全方法。可以用它比较某个细节的两个版本，或将拥挤的画布清理到只剩你正在处理的部分。

菜单为当前选择提供了相同的功能：对象 › 隐藏 › 所选对象（⌘3）隐藏所选内容，对象 › 显示全部（⌥⌘3）显示所有被隐藏的内容。

锁定

单击行上的锁即可将其锁定。锁定的对象保持可见，但无法在画布上被选择或更改，因此在你围绕它工作时它不会受到影响。锁定一个图层会同时保护其上的所有内容。在背景上方绘制时锁定背景，或锁定已完成的元素，以免一次误拖将其移动。

在菜单中，对象 › 锁定 › 所选对象（⌘2）锁定所选内容，对象 › 全部解锁（⌥⌘2）再次释放所有内容。锁定所选对象也会将其从选择中移除，因为被锁定的东西已无法再对其进行操作。

选择与当前图层

在面板中单击对象的行，即可在画布上选择该对象。单击时按住 ⇧、⌘ 或 Ctrl 可将另一个对象添加到选择中，这样你就能从列表中逐步建立选择，而不必在页面上寻找细小的形状。

单击图层行的作用则不同：它会将该图层设为当前图层，并在其左边缘标记一条彩色竖条。你绘制、置入或粘贴的新图稿都会添加到当前图层中，因此在开始之前单击某个图层，就决定了作品的落脚之处。创建新图层会立即将其设为当前图层。

每行右侧的选择方块将面板与画布联系起来。它以图层的颜色出现在包含当前选择内容的每一行上，并在被选中的具体对象上显示为实心。由于这一标记会沿树向上传递，扫一眼列表就能同时看出选中了什么，以及这些对象位于哪些图层和编组中。

颜色标签

每个图层都会从一个固定序列中获得一种颜色（浅蓝、红、绿、蓝、黄等，共十二种，添加更多图层时循环使用）。这种颜色就是图层的标签。它显示为图层名称旁的颜色标记，并为面板中的选择标记着色，同时也为画布上该图层对象的选择高亮和定界框着色。其目的是快速识别：当你选中某个对象而它的框显示为绿色时，你立刻就知道它属于绿色图层。将文档分布在几个命名清晰、颜色各异的图层上，会让你更容易掌握每样东西的位置。

剪切蒙版和不透明度蒙版

图层或编组可以带有自己的不透明度和混合模式，两者都在透明度面板（窗口 › 透明度，⇧⌘F10）中设置。同一面板中还有将混合限制在编组内，它让编组的混合模式只在编组内部相互混合，而不与下方的内容混合；以及挖空组，其中编组内的每个对象都会遮住其后方的对象，而不是透出它们。蒙版则更进一步，让一个对象控制其他图稿显示的位置或显示的强度。

剪切蒙版

剪切蒙版将图稿裁切为某个形状。选择两个或更多对象，然后选择对象 › 剪切蒙版 › 建立（⌘7）。所选对象中最上面的一个成为剪切路径，其下方的所有内容只在该形状内部显示；其余部分被剪掉。结果是一个剪切组，在面板中以虚线图标显示。释放（⌥⌘7）可撤销剪切并交还各个对象。可以用它把照片或繁杂的图案裁切为圆形、字母或你在上方绘制的任何轮廓。

不透明度蒙版

不透明度蒙版根据另一个对象的明度使图稿淡化。选择两个或更多对象，然后选择对象 › 剪切蒙版 › 建立不透明度蒙版，或使用透明度面板中的制作蒙版。最上面的对象成为蒙版：蒙版亮的地方，下方图稿完全显示；暗的地方，图稿淡化至完全消失；介于其间的灰色则产生部分透明。释放不透明度蒙版会将其重新拆开。用从白到黑的渐变作为蒙版，可以让图片向一侧边缘淡出，或制作单一的固定不透明度值无法实现的柔和晕影和过渡。

组织文档

早一点建立一些结构，可以省去之后大量的寻找。一些值得养成的习惯：

每项内容一个图层
将背景、主体图稿和文字放在不同的、已命名的图层上。这样你只需单击一次，就能隐藏、锁定或重新排序绘图的整个部分。
锁定你不需要改动的内容
锁定你正在处理的图层周围的图层，以免一次误点或误拖打乱它们；需要时再用 ⌥⌘2 解锁。
将一起移动的东西编组
将单个元素的各个部分绑定为一个编组，使其像一个对象一样运作，而把图层留给文档中较大的划分。
绘制之前先设置当前图层
先单击你要添加内容的图层，这样新图稿就会落在正确的位置，而不是叠在原有内容的上方。
让颜色为你指路
善用图层颜色：当选择的高亮与某个图层的颜色标记一致时，你无需展开任何内容就能准确知道该对象位于何处。
