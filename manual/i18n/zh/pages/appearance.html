形状的样子就是它的外观：轮廓内部的填色、沿轮廓绘制的描边，以及决定它如何叠在后方内容之上的不透明度和混合。其中每一项都可以是纯色、渐变或图案，并且一个对象可以同时带有多个填色和多个描边。本页介绍上色控件、颜色模型、色板、渐变、描边、透明度、绘制堆栈面板以及图形样式。

下文中的快捷键以 macOS 形式书写。在 Windows 上，请将 ⌘ 视为 Ctrl，⌥ 视为 Alt，⇧ 视为 Shift。

填色和描边

路径、形状或文字可以带有填色（轮廓内部的颜色）和描边（沿轮廓绘制的线条）。填色可以是纯色、渐变或图案；描边可以是纯色或渐变，并有自己的粗细和虚线设置。任意一方也可以设为无，因此你可以绘制只有描边或只有填色的形状。

填色和描边色块

工具栏底部有两个相互重叠的色块，分别代表填色和描边。单击任意一个即可打开拾色器；位于前面的那个就是按键以及颜色、渐变和色板面板所作用的一方。按 X 将另一方调到前面，按 ⇧X 互换两种颜色，按 / 将前面的一方设为无，按 D 恢复默认值：白色填色、黑色描边和 1 pt 粗细。同样的填色、描边、粗细、不透明度和混合模式也集中在属性面板中，当你想把它们都放在一处时很方便。

未选择任何内容时，这些控件设置的是你接下来绘制的对象将采用的样式，因此你可以在绘制之前而不是之后选择颜色。

用吸管工具复制颜色

吸管工具（I）将你单击的对象的整个外观复制到所选对象上。按住 ⇧ 只将其填色或描边颜色取到当前一方，按住 ⌥ 则反过来将所选对象的外观应用到指针下的对象上。单击置入的图像或像素图层，会将指针下的颜色取样到当前一方，因此你可以直接从照片中提取颜色。当两个对象需要一致时就使用吸管工具：对其中一个取样，另一个只需单击一次就能获得相同的颜色。

颜色

颜色可以在每个色块的小型弹出拾色器中选择，也可以在颜色面板中进行更精细的控制。

颜色面板

颜色面板（F6）以一组滑块、一个十六进制字段和一个色谱显示当前一方的颜色。顶部的填色和描边色块用于选择你正在编辑的一方。色谱横向排列各种色相，顶部为白色，底部为黑色；在其中单击或拖动即可选取颜色。旁边的三个快捷色板只需单击一次即可设置为无、白色或黑色，反相和补色按钮会改造当前颜色（补色将其色相旋转半圈，同时保持饱和度和亮度不变）。

颜色模型菜单设置面板显示哪些滑块。该选择在本次会话中保持不变，新色板也会以该模型创建。

灰度
单个 K 滑块，从 0% 的白色到 100% 的黑色。
RGB
红、绿、蓝，取值 0 到 255，用于屏幕作品的模型。
HSB
以度为单位的色相，以及以百分比表示的饱和度和亮度：通常是在不失去颜色特质的前提下微调颜色的最快方法。
CMYK
以百分比表示的青、洋红、黄和黑，用于印刷。
Web 安全 RGB
对齐到 216 种 Web 安全颜色的 RGB。当前颜色不属于其中时会出现一个警告三角形；单击它即可对齐到最接近的 Web 安全颜色。

当前一方使用全局色板上色时，滑块上方会出现一行色调设置：它显示色板名称，并让你设置 0% 到 100% 的色调，而不是直接编辑颜色，这样图稿就能保持与色板的链接。

色板和颜色组

色板是随文档存储的命名颜色。用色板上色而不是输入数值，可以保持调色板的一致性；对于全局色板，只需编辑一种颜色就能为整个文档重新设定风格。

色板面板

色板面板（从窗口 › 色板打开）以网格或列表的形式列出文档的色板；列表视图还会显示每个色板的颜色模型。普通单击会为当前一方上色。按住 ⇧ 单击可选取一串连续的色板，按住 ⌘ 单击可在选择中添加或移除一个色板，因此你可以同时对多个色板进行操作。底部的按钮用于切换视图、打开面板菜单、显示色板选项、建立颜色组、新建色板以及删除所选内容。

面板菜单提供了更多功能：添加使用的颜色和添加选中的颜色将文档中或仅所选内容中已有的颜色转为色板；选择所有未使用的色板会挑出所有没有用于任何上色的色板，以便删除；重新映射颜色…则打开下文介绍的重新着色对话框。

印刷色、专色和全局色板

双击色板可打开色板选项，在其中设置它是哪种颜色。

印刷色
为工作调配的普通颜色。普通的印刷色色板只是一个存储的颜色：编辑它不会影响已用它上色的图稿。
全局
标记为全局的印刷色色板会保持图稿与它的链接，因此重新设置色板的颜色会一次性重新绘制所有用它上色的内容。全局色板可以作为色调应用。
专色
一种命名油墨，用于单独的印版印刷。专色始终是全局的。

每个文档一开始还带有一个固定的 [套版色] 色板，它没有自己的颜色类型，无法删除或拖动。当某种颜色多次出现且可能更改时，请使用全局色板或专色色板：一次编辑就能更新每个对象，而不必手动逐个寻找。

颜色组

颜色组将相关的色板归类在一起，例如同一色系或同一项目的调色板。将色板拖到组上即可归入，或选择一些色板并用面板的新建颜色组按钮从中建立组。双击组的标题可打开其选项。在每个色块的拾色器中，每个组显示为一行，因此一个色系呈现为一条渐进的色阶，而不是一整面色块。

渐变

渐变在两种或更多颜色之间过渡。Scissor 可以创建线性、径向和任意形状渐变，面板和画布上的工具都可以构建和调整它们。用渐变为平面形状增添深度、为背景铺上柔和的色调，或为按钮添加光泽。

渐变面板

渐变面板（⌘F9）控制整个渐变。单击缩览图为当前一方填充渐变，从类型菜单中选择线性、径向或任意形状，用反向按钮将色带首尾翻转。色带本身带有色标：单击色带可在该处以已有的颜色添加色标，拖动色标可移动它，拖动两个色标之间的菱形可移动两种颜色交汇的位置。所选色标有自己的色板、不透明度字段和位置字段，删除色标可将其移除。角度旋转线性或径向渐变，长宽比（仅限径向）将径向渐变压扁为椭圆。

渐变工具

使用渐变工具（G）时，同样的控件会直接出现在图稿上。在对象上拖动以放置渐变轴，按住 ⇧ 可将其约束为以 45° 为增量。渐变轴起点显示一个圆形控制点，终点显示一个方形控制点；拖动任意一个即可移动该端。单击渐变轴可在该处以已有的颜色添加色标，沿轴拖动色标，将色标拖离轴足够远即可删除它。拖动菱形可移动中点。Delete 删除你最后触碰的色标。

任意形状渐变

任意形状渐变可以在形状上的任意位置放置色点，而不是沿一条轴排列，因此过渡可以顺应图稿的形态。使用渐变工具时，单击图稿可放置色点，拖动色点可移动它，按 Delete 可将其删除。在面板中勾选将点串成线可将各点连接成线，使颜色沿一段线条铺展，而不是从单个点向外扩散。用任意形状渐变来实现直线色带无法提供的柔和、自然的明暗。

图案

图案是作为拼贴重复并用作填色的图稿。用对象 › 图案 › 建立将所选内容转换为拼贴，然后从图案面板中为任意形状填充它：单击拼贴可填充，双击可编辑，按住 ⌥ 单击可删除。拼贴选项设置拼贴类型、砖形位移、尺寸和间距，以及拼贴是否随图稿调整大小和移动。编辑图案会就地打开拼贴，在你工作时其副本会在周围重复显示；拼贴调整好后，在图案面板中单击完成编辑。图案适用于手绘会很繁琐的重复纹理，例如条纹、圆点、编织纹和背景。

描边

描边面板（⌘F10）用于设置沿路径绘制的线条形态。

粗细、端点、边角和对齐

粗细以点为单位设置描边的粗细。端点按钮决定开放路径如何结束：平头（在锚点处方正截断）、圆头，或方头（方形，但超出锚点半个粗细的长度）。边角按钮决定描边如何转角：斜接（尖角）、圆角或斜角（平切），斜接限制会将最尖的角切成斜角，使其不会尖刺般突出。对齐将描边放在路径的中央，或完全放在路径内侧或外侧，当形状必须与相邻形状严丝合缝时，这一点很重要。

虚线

勾选虚线可将描边断开成虚线。下方的三对虚线和间隙字段设置图案：第一个字段是虚线长度，下一个是间隙，依此类推，沿路径循环重复。后面几对留空即可得到简单均匀的虚线。

宽度配置文件和宽度工具

宽度配置文件使描边沿其长度逐渐变细，而不是保持单一粗细。从面板的菜单中选择一个配置文件，小预览会显示其形状；旁边的按钮可将配置文件反向、将当前描边存储为新的配置文件，或删除你创建的配置文件。手动调整过的描边会在菜单中显示为自定。

宽度工具（⇧W）直接在画布上调整描边：从路径向外拖动可加宽该处，向路径拖动则使其变窄，并留下一个宽度点，之后可以再次拖动。用它为绘制的线条赋予毛笔或笔尖般的粗细变化。

画笔

画笔面板（F5）用形状而非普通线条来绘制描边。它包含书法画笔、散点画笔、艺术画笔、毛刷画笔和图案画笔。单击画笔可将其应用于所选路径；画笔工具使用当前画笔。双击画笔可打开其选项，使用新建画笔…创建画笔（散点、艺术和图案画笔由所选图稿构建），使用移去画笔将描边恢复为普通线条。

不透明度和混合

不透明度和混合模式决定对象如何与其下方的内容结合。它们位于透明度面板（⇧⌘F10）中，也位于属性面板中。

混合模式

不透明度从 0%（不可见）到 100%（完全不透明）。模式菜单提供十六种混合模式，可分为几组：变暗模式、变亮模式、对比模式、比较模式，以及借用颜色某一成分的四种模式。

模式作用
正常覆盖在下方内容之上，不进行混合。
变暗逐个通道保留较暗的颜色。
正片叠底将两种颜色相乘，结果总是变暗；白色使基色保持不变。
颜色加深加深基色以呈现混合色。
变亮保留较亮的颜色。
滤色正片叠底的反向，结果总是变亮；黑色使基色保持不变。
颜色减淡提亮基色以呈现混合色。
叠加根据基色进行正片叠底或滤色，提高对比度。
柔光柔和的减淡或加深，仿佛有一束柔光照在图稿上。
强光根据混合色进行正片叠底或滤色，如同一束刺眼的聚光灯。
差值从较亮的颜色中减去较暗的颜色；白色使基色反相，黑色没有效果。
排除与差值类似，但更柔和、对比度更低。
色相采用混合色的色相，以及基色的饱和度和亮度。
饱和度采用混合色的饱和度，以及基色的色相和亮度。
混色采用混合色的色相和饱和度，以及基色的亮度：适合为灰度图稿着色。
明度采用混合色的亮度，以及基色的色相和饱和度。

对于编组，有两个开关可改变其混合方式。将混合限制在编组内使编组的混合模式只作用于编组内部，因此其成员之间相互混合，但不与编组后方的图稿混合。挖空组使每个成员遮住编组内其下方的成员，而不是向下透过它们混合。

不透明度蒙版

不透明度蒙版按色调使图稿淡化。选择图稿以及位于其上方、用作蒙版的形状，然后单击制作蒙版（也可使用对象 › 剪切蒙版 › 建立不透明度蒙版）。上方的对象成为蒙版：它亮的地方图稿显示，暗的地方图稿淡出，因此从白到黑的渐变可以做出平滑的淡出效果。释放会交还这两个对象。用蒙版制作硬性剪切无法实现的柔和边缘或晕影。

绘制堆栈面板

绘制堆栈面板（⇧F6）列出绘制在一个对象上的所有内容：它的填色和描边，以及位于其上的所有实时效果。由于一个对象可以带有多个填色和描边，这里就是你将它们叠放的地方，例如在一条细的浅色描边下放一条宽的深色描边来制作轮廓，或叠放两个不透明度不同的填色。

堆栈从上往下显示，与绘制的顺序一致。每个填色或描边行都有一个用于隐藏的眼睛、一个打开拾色器的颜色色块、一个不透明度字段、一个描边专用的粗细字段，以及在堆栈中上移或下移的箭头，另有一个移除按钮。添加新填色和添加新描边会在顶部再添加一个。效果显示在填色和描边之上，并带有 fx 徽标；单击效果可编辑其选项，或从其所在行将其移除。当分层外观完成后，对象 › 扩展外观会将整个堆栈烘焙为普通图稿。

图形样式

图形样式是一种可以应用于其他对象的已存储外观。图形样式面板（⇧F5）将它们保存为色块，每个色块显示其填色，并以描边作为色块的边框。选择一个对象并单击新建图形样式可存储其填色和描边；单击色块可将该样式应用于所选对象，按住 ⌥ 单击色块则将其删除。当同一种外观（例如统一的按钮处理方式或标签样式）需要用于许多对象并保持一致时，就值得创建样式。

叠印

特性面板（⌘F11）为印刷作品设置叠印。叠印填充和叠印描边使该油墨印在下方颜色之上，而不是将其挖空，这用于补漏白，以及例如黑色叠印在下方内容之上而不是替代它的效果。开启视图 › 叠印预览可在屏幕上查看效果；PDF 导出会保留这一设置。

重新着色图稿

编辑 › 编辑颜色 › 重新映射颜色…列出所选内容中的每种颜色及其使用频率。单击行右侧的色块可选择该颜色要变成的颜色，单击两个色块之间的箭头则保持该颜色不变。色相、饱和度和亮度滑块可整体调整所有颜色，另有两个按钮可随机重新排列新颜色，或随机调整其饱和度和亮度，这是快速尝试各种变化的方法。图稿会随操作实时更新，重置则恢复为最初的颜色。

同一子菜单还提供一步完成的更改：前后混合在最前面和最后面的对象之间铺展一串颜色，转换为灰度去除所有颜色，反相颜色将每种颜色反相，调整饱和度…则提高或降低所选内容的饱和度。
