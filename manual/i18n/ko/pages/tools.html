도구 모음은 창 왼쪽을 따라 세로로 놓여 있으며 그리기, 편집, 보기 도구가 모두 들어 있습니다. 각 칸에는 도구 하나 또는 관련 도구 그룹이 들어 있습니다. 이 페이지에서는 도구 모음에 놓인 순서대로 모든 도구를, 각 도구를 고르는 키와 용도와 함께 소개합니다.

칸을 길게 누르거나 마우스 오른쪽 버튼으로 클릭하면 플라이아웃이 열려 그룹의 다른 도구를 고를 수 있습니다. 도구 단축키는 키 하나만 누르면 되며, 텍스트나 입력란에 입력하는 중이 아니면 언제든 작동합니다.

아래 단축키는 macOS 기준으로 표기되어 있습니다. Windows에서는 ⌥를 Alt로, ⌘를 Ctrl로, ⇧를 Shift로 바꿔 읽으십시오.

거의 모든 도구에 적용되는 세 가지 습관이 있습니다.

  • 스페이스바를 누르고 있으면 잠시 손 도구로 바뀌고, 놓으면 사용하던 도구로 돌아갑니다.
  • ⌘ 키를 누르고 있으면 같은 방식으로 잠시 선택 도구로 바뀝니다. 단, 자유 변형 도구는 ⌘ 키를 직접 사용하므로 예외입니다.
  • Esc 키를 누르면 진행 중인 드래그나 그리던 패스가 취소되고 아트워크가 원래대로 남습니다.

두 칸(모양 변경 도구와 인쇄 바둑판식 배열 도구)은 목록을 완전하게 하려고 실었지만 아직 기능이 없습니다. 도구 모음에는 출시 예정으로 표시되며 엔진은 이 도구를 거부합니다.

선택 도구

이 네 도구는 다음에 작업할 대상을 고릅니다. 개체 전체는 선택 도구로, 패스 안의 기준점과 선분은 직접 선택 도구로, 같은 방식으로 칠한 모든 것은 자동 선택 도구로, 기준점 여러 개를 손으로 둘러 잡을 때는 올가미 도구로 선택합니다.

선택

도구단축키기능
선택 도구V개체를 클릭하면 개체 전체가 선택되고, ⇧-클릭하면 개체를 선택에 추가하거나 제외하며, 빈 캔버스를 드래그하면 선택 윤곽이 그려집니다. 선택 영역 안을 드래그하면 이동하며, ⇧ 키는 이동을 45° 단위로 제한하고 ⌥ 키는 사본을 남깁니다.

개체를 선택하면 테두리 상자에 핸들 여덟 개가 나타납니다. 핸들을 드래그하면 크기가 조절되며, ⇧ 키를 누르면 비율이 유지되고 ⌥ 키를 누르면 중심을 기준으로 크기가 조절됩니다. 모퉁이 바로 바깥쪽을 드래그하면 회전하며, ⇧ 키를 누르면 45° 단위로 물립니다. 그룹을 더블클릭하면 그룹 안으로 들어가 작업할 수 있고, 텍스트를 더블클릭하면 편집할 수 있으며, 심볼 인스턴스를 더블클릭하면 모든 인스턴스가 그리는 심볼 자체를 편집할 수 있습니다. 아트워크 바깥을 더블클릭하면 다시 밖으로 나옵니다.

편집 가능한 모양에는 고유한 위젯이 있습니다. 모퉁이 위젯을 드래그하면 모양의 모든 모퉁이가 한 번에 둥글어지고, ⌥-클릭하면 모퉁이가 다음 종류로 바뀝니다. 가장 많은 시간을 보내게 될 도구이므로 핸들을 잘 익혀 두는 것이 좋습니다.

직접 선택과 그룹 선택

도구단축키기능
직접 선택 도구A기준점, 핸들, 선분을 클릭한 다음 드래그하여 패스의 모양을 바꿉니다. 빈 캔버스에서 선택 윤곽을 그리면 그 안의 기준점이 선택됩니다. ⇧ 키는 선택에 추가하고 드래그를 45°로 제한하며, 핸들을 드래그하는 동안 ⌥ 키를 누르면 핸들 쌍이 분리되어 기준점이 모퉁이가 됩니다.
그룹 선택 도구–개체를 클릭하면 선택됩니다. 다시 클릭하면 개체가 속한 그룹이, 한 번 더 클릭하면 그 위의 그룹이 선택됩니다.

직접 선택 도구는 그린 모양을 세밀하게 다듬을 때 사용합니다. 기준점 하나를 살짝 옮기거나, 핸들 하나를 당기거나, 곡선의 모양을 바꿀 수 있습니다. 엔벨로프 메시의 교차점을 드래그하여 엔벨로프에 담긴 내용을 구부릴 수도 있고, 라이브 모양의 모퉁이를 모두가 아니라 하나씩 둥글게 만들 수도 있습니다. 그룹 선택 도구를 사용하면 중첩된 그룹을 들락거리지 않고도 그 안에 묻힌 개체를 빠르게 선택할 수 있습니다.

자동 선택

도구단축키기능
자동 선택 도구Y개체를 클릭하면 같은 방식으로 칠한 모든 개체가 선택됩니다. 무엇을 같다고 볼지(칠, 획, 획 두께, 불투명도, 혼합 모드)는 자동 선택 패널에서 설정하며, ⇧ 키를 누르면 새로 일치하는 개체가 선택에 추가됩니다.

한 가지 색상으로 된 모든 모양을 한꺼번에 바꾸고 싶을 때 사용합니다. 빨간색 모양 하나를 클릭한 다음 선택 전체의 색상을 한 번에 바꾸면 됩니다.

올가미

도구단축키기능
올가미 도구Q자유로운 고리 모양으로 드래그하여 그 안의 기준점을 선택합니다. ⇧ 키를 누르면 이미 선택된 기준점에 추가됩니다.

원하는 기준점이 반듯한 사각형 안에 모여 있지 않아 선택 윤곽으로는 너무 많거나 너무 적게 잡힐 때 사용합니다.

이 칸에는 픽셀 선택 도구인 사각형 선택 윤곽 도구, 타원 선택 윤곽 도구, 올가미 선택 윤곽 도구도 들어 있습니다. 이 도구들은 벡터 기준점을 고르는 대신 픽셀 레이어에 점선으로 움직이는 선택 영역을 그립니다. 자세한 내용은 픽셀 레이어 페이지에서 다룹니다.

펜, 곡률, 문자

새 패스와 텍스트를 만드는 도구입니다. 펜 도구 계열은 모든 기준점과 핸들을 정확하게 제어할 수 있게 해 주고, 곡률 도구는 찍은 점들을 지나는 매끄러운 선을 맞추며, 문자 도구는 포인트 문자, 영역 문자, 패스 상의 문자, 세로 문자를 입력합니다.

펜 도구 계열

도구단축키기능
펜 도구P클릭하면 모퉁이 점이 찍히고, 누른 채 드래그하면 그 점에서 매끄러운 핸들이 나옵니다. 첫 번째 기준점을 클릭하면 패스가 닫힙니다. ⇧ 키는 새 점이나 핸들을 45°로 제한하고, 드래그하는 동안 ⌥ 키를 누르면 핸들이 분리되어 패스가 기준점에서 독자적인 각도로 뻗어 나갑니다.
기준점 추가 도구+선분을 클릭하면 패스 모양을 바꾸지 않고 그 위치에 기준점이 추가됩니다.
기준점 삭제 도구−기준점을 클릭하면 제거되고 양쪽 선분이 연결됩니다.
기준점 도구⇧C기준점을 드래그하면 짝을 이룬 핸들 한 쌍이 나오고, 클릭하면 핸들이 거두어져 모퉁이가 됩니다. 핸들 하나만 드래그하면 그쪽만 움직이며, ⇧ 키를 누르면 45°로 제한됩니다.

펜 도구는 로고 윤곽선부터 레터링 패스까지 정밀한 그리기를 담당하는 주력 도구입니다. 패스를 그리는 중에 Enter 또는 Esc 키를 누르면 패스가 완료되고, Backspace 키를 누르면 마지막 기준점이 취소됩니다. 세 가지 보조 도구는 완성된 패스에서 기준점을 추가, 제거, 변환합니다. 펜과 연필은 패스 페이지에서 더 자세히 다룹니다.

곡률

도구단축키기능
곡률 도구⇧~클릭하여 점을 찍으면 그 점들을 지나는 매끄러운 곡선이 맞춰집니다. ⌥-클릭하면 대신 모퉁이 점이 찍힙니다. 점을 드래그하면 이동하고, 점을 더블클릭하면 매끄러운 점과 모퉁이 점 사이에서 전환되며, 첫 번째 점을 클릭하면 패스가 닫히고, 패스에서 떨어진 곳을 더블클릭하면 완료됩니다.

흐르는 듯한 선을 원하고, 핸들을 하나하나 직접 당기기보다 점만 찍고 핸들은 Scissor에 맡기고 싶을 때 곡률 도구를 사용합니다.

문자

도구단축키기능
문자 도구T클릭하면 포인트 문자가, 상자를 드래그하면 영역 문자가 만들어지며, 기존 텍스트를 클릭하면 편집할 수 있습니다. 열린 패스를 클릭하면 문자가 패스를 따라 흐릅니다.
영역 문자 도구–문자가 흘러 들어갈 상자를 드래그하여 만듭니다.
패스 상의 문자 도구–패스를 클릭하면 문자가 패스를 따라 흐릅니다. 패스는 기준선이 되므로 더 이상 독립된 아트워크가 아닙니다.
세로 문자 도구–문자 도구와 같지만 문자 행이 페이지를 가로지르지 않고 위에서 아래로 흐릅니다.
글리프 편집 도구⇧T문자 하나를 클릭하여 행에서 골라낸 다음, 드래그하여 이동하거나 모퉁이 손잡이를 드래그하여 크기를 조절하거나 위쪽 손잡이를 드래그하여 회전합니다. ⇧ 키를 누르면 모퉁이 크기 조절 시 비율이 유지되고 회전이 11.25° 단위로 물리며, Delete 키를 누르면 문자가 텍스트에서 원래 놓였던 자리로 돌아갑니다.

대부분의 작업은 문자 도구 하나로 충분합니다. 제목은 클릭하고, 단락은 상자를 드래그하면 됩니다. 글리프 편집 상자의 측면 손잡이는 문자를 한 방향으로만, 즉 가로로는 폭을, 세로로는 높이를 늘이므로 텍스트에서 분리하지 않고도 제목의 글자를 하나하나 다듬을 수 있습니다. 텍스트는 문자 페이지에서 자세히 다룹니다.

선과 모양

미리 정해진 형태를 그리는 모든 도구입니다. 직선, 호와 나선형, 선으로 된 격자, 그리고 그림의 바탕이 되는 사각형, 타원, 다각형, 별을 그립니다.

선, 호, 나선형, 격자

도구단축키기능
선분 도구\드래그하여 직선을 그립니다. ⇧ 키는 45° 단위로 제한하고, ⌥ 키는 끝점이 아닌 중간에서부터 선을 그립니다.
호 도구–호가 채울 상자를 드래그하여 만듭니다. ⇧ 키를 누르면 상자가 정사각형이 됩니다. 화살표 키로 호를 더 평평하거나 더 볼록하게 구부리고, C 키로 호를 닫거나 열며, F 또는 X 키로 휘는 방향을 뒤집습니다.
나선형 도구–중심에서 바깥으로 드래그합니다. 거리가 반경을, 방향이 나선의 시작 위치를 정합니다. ⌥ 키는 감기는 방향을 반대로 하고, R 키는 이를 계속 유지하며, 화살표 키로 선분을 추가하거나 제거합니다.
사각형 격자 도구–드래그하여 격자를 그립니다. ⌥ 키는 중심에서부터 그리고 ⇧ 키는 정사각형을 유지합니다. 위아래 화살표 키로 행 수를, 왼쪽과 오른쪽 화살표 키로 열 수를 바꿉니다.
극좌표 격자 도구–드래그하여 격자를 그립니다. ⌥ 키는 중심에서부터 그리고 ⇧ 키는 원형을 유지합니다. 위아래 화살표 키로 동심원 수를, 왼쪽과 오른쪽 화살표 키로 방사형 분할선 수를 바꿉니다.

두 격자 도구는 선마다 패스를 하나씩 만들기 때문에 모든 선을 따로 선택할 수 있습니다. 표, 달력, 레이아웃 뼈대에는 사각형 격자를, 다트판, 방사형 차트, 시계 문자판에는 극좌표 격자를 사용합니다. 이 도구들은 계속 남는 격자 아트워크를 그립니다. 이는 보기 › 격자 › 격자 표시로 켜는 아트보드의 배경 격자와는 다릅니다. 배경 격자는 화면에서만 쓰는 그리기 보조 도구로 인쇄되지 않으며, 일곱 가지 종류(사각형, 등각, 육각형, 사선, 황금비, 패턴, 원근)가 있습니다. 배경 격자는 격자 페이지에서 다룹니다. 별도의 격자 모양 도구(⇧G)는 배경 격자의 칸을 클릭하거나 드래그하여 채워진 패스를 만듭니다. 등각 격자나 육각형 격자 위에 단색 블록을 빠르게 배치할 수 있습니다.

사각형, 타원 및 기타 모양

도구단축키기능
사각형 도구M드래그하여 사각형을 그립니다. ⇧ 키는 정사각형을 유지하고, ⌥ 키는 중심에서부터 그립니다.
둥근 사각형 도구–같은 방식으로 드래그하되 모퉁이가 둥근 사각형을 그립니다. 그리는 동안 위아래 화살표 키로 모퉁이 반경을 늘이거나 줄입니다.
타원 도구L드래그하여 타원을 그립니다. ⇧ 키를 누르면 원이 되고, ⌥ 키를 누르면 중심에서부터 그립니다.
다각형 도구–중심에서 바깥으로 드래그합니다. 드래그 방향에 따라 다각형이 회전하며, ⇧ 키를 누르면 똑바로 선 상태를 유지합니다. 화살표 키로 변을 추가하거나 제거합니다.

핀 뒤틀기는 그려 놓은 팔을 구부리듯 아트워크 하나의 자세를 잡거나 구부리는 도구로, 움직이지 않아야 할 부분에 핀을 꽂고 나머지를 드래그합니다. 이 도구에서 Delete 키는 아트워크가 아닌 선택한 핀을 제거하고, ⌘A 키는 모든 핀을 선택합니다. 드래그 한 번이 실행 취소 한 단계이며, 실행 취소하면 핀도 함께 있던 아트워크와 함께 되돌아옵니다. 문자, 이미지, 심볼 인스턴스는 왜곡할 수 없으므로 그대로 남습니다.

병합 및 분할, 영역 칠, 원근

겹치는 모양을 결합하고 색을 칠할 영역으로 다루는 도구들과, 원근에 맞춰 아트워크를 그리고 배치할 수 있게 해 주는 격자입니다.

병합 및 분할과 영역 칠

도구단축키기능
병합 및 분할 도구⇧M겹치는 모양을 선택한 상태에서 합치려는 영역을 가로질러 드래그하면 하나의 개체가 됩니다. ⌥-드래그하면 대신 지나간 영역이 삭제됩니다.
영역 칠 페인트통K영역 칠 그룹의 면을 클릭하면 현재 칠로 채워집니다. ⌥-클릭하면 칠하지 않고 그 자리에 이미 있는 칠을 가져옵니다. 클릭하기 전에 포인터 아래의 면에 윤곽선이 표시됩니다.
영역 선택 도구⇧L영역 칠 그룹의 면을 클릭하면 칠하지 않고 선택만 합니다.

병합 및 분할 도구로 겹치는 모양 몇 개를 그린 다음, 조각들을 가로질러 드래그하여 합치고 잘라 원하는 윤곽선을 만듭니다. 영역 칠은 겹치는 패스 묶음을 색칠 공부 그림처럼 다룹니다. 페인트통은 둘러싸인 각 면을 색상으로 채우고, 선택 도구는 면과 가장자리를 골라 스타일을 바꿀 수 있게 해 주므로 먼저 모양을 잘라 나눌 필요가 없습니다.

원근

도구단축키기능
원근 격자 도구⇧P격자를 표시하고 형태를 잡습니다. 소실점을 드래그하고, 소실점 하나를 위아래로 드래그하여 지평선을 옮기며, 격자의 가까운 모퉁이를 드래그합니다. 1~4 키나 화면의 위젯으로 그릴 평면을 고릅니다.
원근 선택 도구⇧V아트워크를 선택하여 평면을 따라 드래그합니다. 아직 격자 위에 있지 않은 아트워크는 드래그한 위치의 활성 평면에 놓입니다.

거리나 상자에 담긴 제품처럼 소실점을 향해 멀어지는 장면과 레터링을 그릴 때 사용합니다. 격자가 표시되어 있는 동안에는 사각형, 둥근 사각형, 타원, 사각형 격자 도구가 평면이 아닌 활성 평면 위에 그리며, 이 도구들에서도 1~4 키로 평면을 고를 수 있습니다.

메시와 그레이디언트

모양 안에 단계적인 색상을 칠하는 두 도구입니다. 개체 전체에 색상 점의 메시를 두거나, 축을 따라 매끄러운 혼합을 만듭니다.

메시

도구단축키기능
메시 도구U개체 안쪽을 클릭하면 그 지점을 지나는 메시 선이 양방향으로 생겨 일반 패스가 메시로 바뀝니다. 메시 점을 클릭하여 고른 다음 색상 패널에서 색상을 지정하고, 점을 드래그하여 이동하며, ⌥-클릭하면 그 점을 지나는 선이 제거됩니다.

과일이나 얼굴의 둥근 하이라이트처럼 직선 그레이디언트로는 표현할 수 없는 부드럽고 자유로운 음영에 메시를 사용합니다.

그레이디언트

도구단축키기능
그레이디언트 도구G선택 영역을 가로질러 드래그하여 활성 칠의 축을 설정합니다. ⇧ 키를 누르면 축이 45° 단위로 제한됩니다. 이미 그레이디언트가 있는 아트워크에서는 대신 주석자를 조작합니다.

그레이디언트 도구를 드래그하여 선형 또는 방사형 혼합의 방향과 범위를 정합니다. 주석자에서는 정지점을 축을 따라 드래그하여 이동하고, 다이아몬드를 드래그하여 두 정지점 사이의 혼합을 옮기며, 축을 클릭하면 그 위치의 색상으로 정지점이 추가되고, 정지점을 축에서 멀리 끌어내면 삭제됩니다(두 개는 남아 있어야 합니다). Delete 키는 마지막으로 건드린 정지점을 제거합니다. 자유형 그레이디언트에서는 도구가 색상 점으로 작동합니다. 아트워크를 클릭하면 칠 색상으로 점이 추가되고, 점을 드래그하면 이동합니다. 그레이디언트는 색상 및 모양 페이지에서 더 자세히 다룹니다.

샘플링, 측정, 모프

한 개체의 모양을 다른 개체로 복사하고, 캔버스에서 거리와 각도를 읽으며, 모양 사이를 여러 단계로 혼합합니다.

스포이트와 측정

도구단축키기능
스포이트 도구I개체를 클릭하면 그 개체의 모양 전체를 샘플링하여 선택 영역에, 아무것도 선택하지 않았으면 기본 스타일에 적용합니다. ⇧ 키를 누르면 칠 또는 획 색상만 활성 쪽으로 샘플링하고, ⌥ 키를 누르면 반대로 선택 영역의 모양을 클릭한 개체에 적용합니다.
측정 도구–두 점 사이를 드래그하여 거리, 오프셋, 각도를 읽습니다. ⇧ 키를 누르면 선이 45° 단위로 제한됩니다. 마지막 측정값은 다음 드래그 전까지 화면에 남아 있습니다.

스포이트는 한 개체를 다른 개체와 똑같이 맞추는 가장 빠른 방법입니다. 마음에 드는 모양을 고르면 선택 영역에 적용됩니다. 측정 도구는 아트워크에 흔적을 남기지 않고 간격이나 각도를 확인할 때 사용합니다.

모프

도구단축키기능
모프 도구W개체 하나를 클릭한 다음 다른 개체를 클릭하면 일련의 중간 단계를 거쳐 둘 사이가 모프됩니다. 모프에 개체를 더 추가하려면 모프 안쪽을 클릭한 다음 추가할 개체를 클릭합니다.

매끄러운 음영 띠나, 패스를 따라 고르게 배치되며 점차 변하는 사본처럼 한 모양이나 색상을 균일한 단계로 다른 것과 혼합할 때 모프 도구를 사용합니다.

심볼

심볼은 여러 번 배치할 수 있는 아트워크로, 모든 사본이 하나의 마스터에 연결됩니다. 심볼 브러시는 이러한 인스턴스를 뿌린 다음 무리 전체를 한꺼번에 다룹니다.

심볼 브러시

도구단축키기능
심볼 분무기 도구⇧S드래그하면 심볼 패널에서 고른 심볼의 인스턴스가 심볼 세트로 뿌려집니다. ⌥ 키를 누르면 인스턴스를 다시 덜어 냅니다.
심볼 이동기 도구–브러시 아래의 인스턴스를 포인터를 따라 끌고 갑니다.
심볼 압축기 도구–브러시 아래의 인스턴스를 한데 모읍니다. ⌥ 키를 누르면 흩어 놓습니다.
심볼 크기 조절기 도구–브러시 아래의 인스턴스를 키웁니다. ⌥ 키를 누르면 줄입니다.
심볼 회전기 도구–브러시 아래의 인스턴스를 드래그 방향을 따르도록 회전합니다.
심볼 색조 도구–브러시 아래의 인스턴스를 칠 색상 쪽으로 색조를 입힙니다. ⌥ 키를 누르면 색조를 다시 걷어 냅니다.
심볼 흐리게 하기 도구–브러시 아래의 인스턴스를 흐리게 합니다. ⌥ 키를 누르면 원래 강도로 되돌립니다.
심볼 스타일 도구–그래픽 스타일 패널에서 고른 그래픽 스타일을 브러시 아래의 인스턴스에 적용합니다. ⌥ 키를 누르면 제거합니다.

언덕 위의 나무나 하늘의 별처럼 반복되는 아트워크를 흩뿌린 다음 다양하게 바꿀 때 사용합니다. 세트를 뿌린 뒤 솎아 내고, 크기를 바꾸고, 회전하고, 색조를 입혀 사본이 도장을 찍은 듯 보이지 않게 합니다. 여덟 도구 모두 [ 키와 ] 키로 브러시 크기를, { 키와 } 키로 브러시 강도를 조절합니다. 선택 영역에 있는 인스턴스에 작동하며, 아무것도 선택하지 않았으면 편집 가능한 모든 인스턴스에 작동합니다.

아트보드와 분할 영역

출력을 위해 캔버스를 구성하는 도구입니다. 아트보드는 아트워크가 놓이는 페이지이고, 분할 영역은 따로 내보낼 사각형을 표시합니다.

아트보드

도구단축키기능
아트보드 도구⇧O캔버스에서 직접 아트보드를 그리고, 이동하고, 크기를 조절합니다. 빈 캔버스를 드래그하면 새 아트보드가 생기며, ⌥ 키는 중심에서부터 그리고 ⇧ 키는 정사각형을 유지합니다. 아트보드 안을 드래그하면 이동하며, ⇧ 키는 이동을 한 축으로 제한합니다. ⇧ 키를 누른 채 모퉁이 핸들을 드래그하면 아트보드의 비율이 유지됩니다.

한 문서 안에 디자인의 다양한 크기나 버전을 위한 페이지를 추가하거나, 그린 내용에 맞춰 페이지 크기를 조절할 때 아트보드 도구를 사용합니다. Delete 키는 활성 아트보드를 제거합니다. 단, 아트보드가 하나는 남아 있어야 합니다.

분할 영역

도구단축키기능
분할 영역 도구⇧K따로 내보낼 사각형을 드래그하여 만듭니다. ⌥ 키는 중심에서부터 그리고 ⇧ 키는 정사각형을 유지합니다. 분할 영역의 가장자리는 정수 픽셀에 맞춰지므로 내보낸 결과가 흐려지지 않습니다.
분할 영역 선택 도구–분할 영역을 고르고, 이동하고, 크기를 조절합니다. Delete 키는 선택한 분할 영역을 제거하고, 더블클릭하면 옵션이 열립니다.

웹 레이아웃의 버튼과 배너처럼 아트보드 하나를 여러 조각으로 나누어 각각 별도의 파일로 내보낼 때 분할 영역을 사용합니다. 내보내기는 열기 및 내보내기 페이지에서 다룹니다.

화면 이동

보기를 이동하고, 회전하고, 확대/축소하는 도구입니다. 이 도구들은 문서를 바꾸지 않으며, 문서를 보는 방식만 바꿉니다.

보기 이동

도구단축키기능
손 도구H드래그하여 보기를 이동합니다. 다른 도구를 사용하는 중에도 스페이스바를 누르고 있는 동안 이 도구를 잠시 쓸 수 있습니다.
보기 회전 도구⇧H드래그하여 창 가운데를 중심으로 보기를 회전합니다. ⇧ 키를 누르면 15° 단위로 물리며, 더블클릭하면 다시 똑바로 돌아옵니다. 문서는 회전하지 않고 보기만 회전합니다.
인쇄 바둑판식 배열 도구–도구 모음에 있지만 아직 구현되지 않았으며, 팔레트에 출시 예정으로 표시됩니다.

손 도구는 스크롤 막대를 건드리지 않고 확대한 그림을 스크롤하며, 보기 회전 도구는 보기 전체를 기울여 비스듬한 선을 편한 각도에서 그린 다음 다시 똑바로 되돌릴 수 있게 해 줍니다.

확대/축소

도구단축키기능
확대/축소 도구Z클릭하면 확대되고 ⌥-클릭하면 축소됩니다. 아트워크 일부에 사각형을 드래그하면 그 부분이 창을 가득 채웁니다.

칠 및 획 컨트롤

도구 모음 아래쪽에는 칠 견본과 획 견본이 앞뒤로 겹쳐 놓여 있습니다. 앞쪽 견본이 활성 쪽이며, 다음에 고르는 색상이 여기에 적용됩니다. 패널을 열지 않고도 몇 가지 단일 키로 이를 조작할 수 있습니다.

단축키기능
D칠과 획을 기본값으로 재설정합니다.
X칠과 획 중 활성 쪽을 전환합니다.
⇧X칠 색상과 획 색상을 서로 바꿉니다.
/활성 쪽을 칠 없음으로 설정합니다.

이 키들로 자주 하는 작업을 빠르게 처리할 수 있습니다. X 키로 칠과 획 사이를 오가고, / 키로 칠이나 획을 없음으로 만들며, D 키로 기본 흑백 상태로 돌아갑니다. 칠과 획, 그리고 설정 방법은 색상 및 모양 페이지에서 다룹니다.
