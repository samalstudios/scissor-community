سێ ئامراز لە Scissor کاری دووبارەبووەوە بۆ تۆ دەکەن: کردارەکان زنجیرەیەک فەرمان تۆمار دەکەن و دووبارە لێیان دەدەنەوە، گۆڕاوەکان دەق و دەرکەوتن لە خشتەیەکی داتاوە دەگۆڕن تا یەک دیزاین ببێتە چەندین دانە، و سکریپتەکان هەموو دەستکارییەکە لە JavaScriptـەوە بەڕێوە دەبەن. هیچیان پێویستیان بە هەژمار یان ڕاژەکار نییە — وەک باقی Scissor لەسەر ئامێرەکەی خۆت کار دەکەن.

کردارەکان: یەک جار تۆمار بکە، لە هەر شوێنێک لێی بدەرەوە

پانێڵی کردارەکان (پەنجەرە › کردارەکان) ئەوەی دەیکەیت تۆمار دەکات و لەسەر دیاریکراوێکی نوێ لێی دەداتەوە. تۆمارکردن دابگرە، ئەو فەرمانانە جێبەجێ بکە کە دەتەوێت بیانگریت — ڕیزکردن، دوورخستنەوە، زیادکردنی سێبەر، زنجیرەکە هەرچییەک بێت — پاشان وەستان دابگرە و ناوێک بدە بە کردارەکە. دەچێتە ناو لیستەکەوە و پیشان دەدات چەند هەنگاوی تێدایە.

کرتە لە کردارێک بکە بۆ لێدانەوەی لەسەر هەرچی ئێستا دیاریکراوە؛ ⌥-کرتە لە یەکێک بکە بۆ سڕینەوەی. لەبەر ئەوەی کردارێک تەنها لیستێکی فەرمانەکانە، ڕووتینێکی ورد لەسەر زۆر تەن دووبارە دەکاتەوە بەبێ ئەوەی هەموو جارێک خۆت هەنگاو بە هەنگاو کرتەی لێ بکەیت.

گۆڕاوەکان: یەک دیزاین، چەندین وەشان

پانێڵی گۆڕاوەکان (پەنجەرە › گۆڕاوەکان) دیزاینێکی جێگیر دەکات بە قاڵبێک کە داتا بەڕێوەی دەبات. دوو شت لەسەر تەنێک دەکرێن بە گۆڕاو:

گۆڕاوکردنی دەق
وشەکانی تەنێکی نووسین بە گۆڕاوێکەوە دەبەستێتەوە، تا کۆمەڵە داتای جیاواز بتوانن دەقی جیاواز لە هەمان شوێندا دابنێن.
گۆڕاوکردنی دەرکەوتن
دەرکەوتن یان نەکەوتنی تەنێک دەبەستێتەوە، تا کۆمەڵەیەک بتوانێت بەشەکانی دیزاینەکە پێبکات یان بیکوژێنێتەوە.

هەڵوەشاندنەوەی بەستنەوە تەنێکی بەستراو دووبارە دەکاتەوە بە جێگیر.

کۆمەڵە داتاکان

کۆمەڵە داتا یەک ڕیزی بەهایە بۆ ئەو گۆڕاوانە — یەک باج، یەک کارت، یەک چوارچێوە. گرتن بەها ئێستاکان وەک کۆمەڵەیەکی نوێ پاشەکەوت دەکات؛ تیرەکان لە کۆمەڵەیەکەوە بۆ دواتر دەڕۆن و دیزاینەکە بەپێی ئەوە نوێ دەبێتەوە. هاوردەکردنی CSV… یەکجار تەواوی دەستەیەک دەخوێنێتەوە — یەک ستوون بۆ هەر گۆڕاوێک، یەک ڕیز بۆ هەر کۆمەڵەیەک — و هەناردەکردنی CSV کۆمەڵەکان دەنووسێتەوە دەرەوە تا لە خشتەیەکی ئەلیکترۆنیدا دەستکارییان بکەیت.

هەناردەکردنی هەموو کۆمەڵەکان بەیەکەوە

هەناردەکردنی کۆمەڵە داتاکان… تەختەی چالاک بۆ هەر کۆمەڵە داتایەک یەک جار دەکێشێت و هەموویان بە یەک گەڕ دەنووسێت، وەک PNG، JPEG، WebP یان SVG. پەڕەیەک باجی ناو، کۆمەڵێک بانەری خۆماڵیکراو یان زنجیرەیەک کارتی تۆڕە کۆمەڵایەتییەکان وەک دەستەیەکی ڕێکوپێکی پەڕگە دێنە دەرەوە، هەریەکە بە داتای خۆی پڕکراوەتەوە.

سکریپتەکان: Scissor لە JavaScriptـەوە بەڕێوە ببە

بۆ هەر شتێک کە لیستێک ناتوانێت دەری ببڕێت، سکریپتێک دەتوانێت. پەڕگە › سکریپتەکان › کۆنسۆڵی سکریپت… دەستکارییەک دەکاتەوە کە تێیدا JavaScript دەنووسیت و لەسەر بەڵگەنامە کراوەکە جێبەجێی دەکەیت؛ سکریپتی تر… (⌘F12) پەڕگەیەکی .js لە دیسکەوە جێبەجێ دەکات. سکریپتێک لە Web Workerێکدا کار دەکات، دوور لە پەڕەکە، بۆیە ناتوانێت دەست لە ڕووکار یان پەڕگەکانت بدات جگە لە ڕێگەی ئەو تەنە scissorـەی پێی دراوە — هەموو بانگکردنێک لەسەر بزوێنەرەکە جێبەجێ دەکرێت و وەڵامی دەدرێتەوە.

تەنی scissor بەشە باوەکان دەگرێتەوە:

دروستکردنی شێوە و نووسین
scissor.rect، roundedRect، ellipse، polygon، star، path و text هونەر دەکێشن؛ هەریەکەیان شوێن و قەبارەیەک وەردەگرێت لەگەڵ تەنێکی هەڵبژاردەکان بۆ fill، stroke و strokeWidth (ڕەنگەکان دەتوانن هەر ڕەنگێکی CSS بن).
خوێندنەوەی بەڵگەنامەکە
await scissor.document() بەرنامەکە، دیاریکراو، چینەکان و تەختەکان دەگەڕێنێتەوە هەروەک پانێڵەکان دەیانبینن؛ scissor.selection() تەنها ئەوەی دیاریکراوە دەگەڕێنێتەوە.
کارکردن لەسەری
scissor.select، group و undo، و scissor.run(command) بۆ هەر فەرمانێکی بزوێنەر بە گشتی — هەمان ئەو فەرمانانەی لیستەکان دەینێرن.
وەڵامدانەوە
scissor.log لە کۆنسۆڵدا دەنووسێت؛ scissor.alert پەیامێک پیشان دەدات.

نموونەیەکی کورت — ئەڵقەیەک لە خاڵی ڕەنگاوڕەنگ و ژێرنووسێک:

const doc = await scissor.document();
scissor.log('Boards:', doc.artboards.length);
for (let i = 0; i < 12; i++) {
  const a = (i / 12) * Math.PI * 2;
  await scissor.ellipse(300 + Math.cos(a) * 120, 260 + Math.sin(a) * 120, 36, 36,
    { fill: `hsl(${i * 30} 80% 60%)` });
}
await scissor.text(230, 270, 'Hello, Scissor', { size: 24 });

کۆنسۆڵی سکریپت دوایین کۆدی جێبەجێکراو هەڵدەگرێت، بۆیە سکریپتێکی کارا کاتێک دەگەڕێیتەوە هەر لەوێیە.
