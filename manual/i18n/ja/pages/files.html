開く、保存、配置、書き出し、プリントは、すべてあなた自身のコンピューター上で行われます。このページでは、ネイティブの .cut ドキュメント、Scissor が読み書きできる形式、そしてアートワークを取り込んだり取り出したりする方法を説明します。

すべてはデバイス上にとどまります

Scissor にはサーバーもアカウントもありません。開いたファイルはあなた自身のコンピューター上のブラウザーで読み込まれ、書き出したファイルはそのままディスクに書き込まれます。何もアップロードされず、あなたが自分でどこかに送らない限り、アートワークがコンピューターの外に出ることはありません。その反面、頼りにできるクラウド上のコピーもないので、他のデスクトップのドキュメントと同じように作品を保存してください。

以下のショートカットでは、Windows と Linux では ⌘ を Ctrl、⌥ を Alt と読み替えてください。

.cut ドキュメント

Scissor 独自の形式は .cut です。これはバージョン管理された JSON ファイルで、ノードツリー全体を保持します。すべてのレイヤー、グループ、パス、ライブシェイプ、テキスト、配置した画像、グラデーション、効果、アートボードが、作業を終えたときのまま保存されます。Scissor でできることをすべて保持できる唯一の形式なので、作業中の作品はこの形式で保存します。書き出し形式は、アートワークを他のプログラムや Web に持ち出す必要があるときにだけ使います。

作品の保存

ファイル > 保存（⌘S）でドキュメントを保存し、別名で保存…（⇧⌘S）で新しい名前で保存し、複製を保存…（⌥⌘S）で元のドキュメントで作業を続けたまま、その時点のスナップショットを別に保存します。

ブラウザーが対応している場合、Scissor は選んだファイルへの参照を保持するので、デスクトップアプリケーションと同じように、以降の保存ではダイアログなしで同じ場所に保存されます。対応していない場合は、保存するたびに新しい .cut ファイルとしてダウンロードされます。保存したファイルがその後移動されたり、アクセス許可が取り消されたりした場合は、改めて保存先を尋ねます。

ドキュメントの作成と終了

ファイル > 新規…（⌥⌘N）は、新規ドキュメントダイアログから空のドキュメントを作成します。ダイアログでは、サイズと最初のアートボードの数を設定します。ファイル > 開く…（⌘O）は既存のファイルを読み込み、複数のファイルを一度に開くこともできます。アクティブなドキュメントを閉じるには、ファイル > 閉じる（⌥⌘W）を使います。

他の形式を開く

ファイル > 開く…（⌘O）では、Scissor 独自のドキュメント以外も読み込めます。複数のファイルを一度に選択することも、カンバスにドラッグすることもできます。何が読み込まれるかは形式によって異なります。

SVG（.svg）
詳細に読み込みます。パスと基本シェイプ（長方形、円、楕円、直線、ポリライン、多角形）、グループ、入れ子の svg、use と symbol、そしてすべての変形が読み込まれます。プレゼンテーション属性、インラインスタイル、シンプルな <style> ルール（タグ、クラス、id による指定）、線形と円形のグラデーション、クリッピングパス、パス上文字を含む基本的なテキスト、埋め込みとリンクの両方の画像も読み込まれます。カラーは 16 進数、rgb、hsl、CSS のカラー名で、長さは px、ポイント、パイカ、インチ、ミリメートル、センチメートル、em、ex で読み込まれます。軸に沿った長方形、円、楕円はライブシェイプとして読み込まれるので、固定されたアウトラインにならず、ハンドルで編集できるままです。レイヤーを持つ SVG は、名前も含めてそのレイヤーを保ったまま開き、非表示やロックされていたレイヤーはそのまま非表示・ロックされます。パターンの塗り、マスク、マーカー、フィルター効果は読み込まれません。
PDF と、PDF ベースの .ai
1 ページにつき 1 つのアートボードになります。パス、カラー、線のスタイル、クリッピング、フォーム XObject、フォントと位置を保ったテキスト、画像（JPEG、インデックスカラー画像、ソフトマスクのアルファを持つステンシルマスクを含む）がすべて読み込まれます。軸方向と放射状のシェーディングは、直接塗られている場合もパターンの塗りを通している場合も読み込まれます。
EPS（.eps、.epsf）
EPS ファイルは PostScript のプログラムなので、Scissor はそれを実行します。パス、変形、クリッピング、グレー、RGB、CMYK、HSB、特色、線幅、線端、角の形状、破線、穴を持つ複合パス、フォントを保ったテキストがすべて読み込まれ、%%BoundingBox コメントがアートボードになります（ファイルに %%HiResBoundingBox があればそちらが優先されます）。よく使われる省略形の演算子は組み込まれているので、それに依存するファイルも独自のプロローグを実行せずに読み込めます。DOS EPS が持つバイナリのラッパーは先に取り除かれます。EPS に埋め込まれたラスター画像はスキップされます。
PSD（.psd）
ピクセルレイヤーは、グループの中で編集可能なピクセルレイヤーとなり、名前、不透明度、描画モード、非表示の状態が保たれます。レイヤーマスクはアルファに統合され、ベクトルマスクとファイルに保存されたパスは編集可能なパスとして、テキストレイヤーは編集可能なテキストとして読み込まれます。描画を行うレイヤースタイル（ドロップシャドウ、シャドウ（内側）、光彩）は、ライブ効果として読み込まれます。

ラスター画像（.png、.jpg、.gif、.webp、.bmp、.avif）も開けます。ファイルダイアログから開いた画像は、画像に合わせたサイズのアートボードを 1 つ持つ独立したドキュメントになります。すでに開いているアートワークの上にドロップした場合は、そのドキュメントに配置されます。

独自の非公開形式を使うデザインプログラムでは、そのファイルを他の誰も読むことができないため、Scissor でも開けません。そのプログラムから SVG または PDF を書き出してください。Scissor はどちらも読み込めます。

.ai を読み込んでも書き出さない理由

最近の .ai ファイルは PDF なので、PDF の読み込み機能で開けます。しかし、.ai を書き出すのは別の問題です。この拡張子は他のプログラムのドキュメントを示すものであり、そのドキュメントを名乗りながら Scissor 独自の構造を持つファイルは、次に開いた人を混乱させてしまいます。Scissor は自身の作品には .cut を、アートワークを持ち出す必要があるときは PDF か SVG を書き出します。

アートワークの配置

ファイル > 配置…（⇧⌘P）は、新しいドキュメントを作らずに、すでに開いているドキュメントに SVG とラスター画像（PNG、JPEG、GIF、WebP）を取り込みます。作成中のレイアウトに、ロゴ、写真、スキャンした線画を置くのに使います。

配置した SVG は、編集可能なアートワークとして取り込まれます。シェイプ、パス、テキストは、平らな画像ではなく、選択して形を変えられるオブジェクトとしてドキュメントに入ります。ラスター画像（PNG、JPEG、GIF、WebP）は、元のサイズのまま編集可能なピクセルレイヤーとして取り込まれます。すぐにペイント、マスク、色調補正、フィルターを適用でき、ベクター化でトレースすることもできます。ピクセルはドキュメント内に保持されるので、移動したり見つからなくなったりするリンクファイルを探しに行くことはありません。非常に大きな写真は、1 つのサーフェスに収まるように縮小されます。

ファイルをカンバスにドラッグすると、配置と同じ動作になります。ただし、.cut、PDF、.ai、.psd、EPS ファイルは独立したドキュメントとして開きます。クリップボードから画像をペーストした場合も配置されます。完成したライブアートワークをピクセルに変換するには、オブジェクト > ラスタライズを使います。選択範囲がその 2 倍の解像度の画像に置き換えられます。

コピー、カット、ペースト

コピー（⌘C）とカット（⌘X）は選択範囲をクリップボードに入れ、ペースト（⌘V）は表示範囲の中央付近に戻します。Scissor はアプリ内でのやり取り用に完全な精度のコピーを独自に保持するとともに、選択範囲を SVG としてシステムのクリップボードにも書き込むので、アートワークを他のプログラムに直接ペーストできます。

ペーストする位置は 3 つの方法で制御できます。前面へペースト（⌘F）と背面へペースト（⌘B）は、重ね順で現在の選択範囲のすぐ上または下に置き、同じ位置にペースト（⇧⌘V）はコピー元と同じ座標に置きます。コピーは SVG としても受け渡されるので、他の場所からコピーしたテキストやアートワークもペーストでき、編集可能なオブジェクトとして取り込まれます。

書き出し

書き出しでは、.cut ドキュメントはそのままにして、共有や Web 用の形式でアートワークのコピーを書き出します。ファイル > 書き出しサブメニューには 1 つのファイルを書き出すコマンドがあり、多数のファイルを一度に扱う方法も 2 つあります。

1 つのファイル

SVG として書き出し…は、アクティブなアートボードを SVG で書き出します。書き出しは徹底しています。ライブの長方形、円、楕円は実際の <rect>、<circle>、<ellipse> 要素として書き出されるので、編集可能なままです。線形と円形のグラデーション、パターンの塗り、クリッピングとノックアウトグループ、不透明度、描画モード、描画モードの分離もすべて書き出されます。ドロップシャドウ、ぼかし、光彩、ぼかし（フェザー）は SVG フィルターとして書き出されます。テキストは、パス上文字、OpenType 機能の設定、アウトライン付きの塗りを含め、テキストのまま残ります。SVG のグラデーションでは表現できないフリーグラデーションとグラデーションメッシュは、多数の小さな色付きのセルとして書き出されるので、どのビューアーでも正しく表示されます。配置した画像とピクセルレイヤーは <image> 要素として埋め込まれます。

PNG として書き出し…、PNG @2x として書き出し…、PNG（透明）として書き出し…は、アクティブなアートボードを等倍または 2 倍のサイズの PNG としてレンダリングします。最後のものは背景を透明にします。JPEG として書き出し…と WebP として書き出し…は、他のラスター形式で書き出します。JPEG には透明度がないので、常にアートボードの背景が残ります。

PDF として書き出し…は、ドキュメント全体を PDF で書き出し、アートボードごとに 1 ページになります。これは独自開発の書き出し機能で、ベクターパス、グラデーション、不透明度、クリッピング、テキスト、配置した画像を透明度とともに保持するので、結果はアートワークを平坦化した画像ではなく、他のプログラムでも編集可能なままです。

選択範囲を書き出し…は、選択したオブジェクトだけを、選んだ範囲で切り抜いて SVG で書き出します。ごちゃごちゃしたアートボードから、アイコンやシェイプを 1 つだけ取り出したいときに使います。

スクリーン用に書き出し

ファイル > 書き出し > スクリーン用に書き出し…（⌥⌘E）は、一度に多数のファイルを書き出します。複数のサイズのアセット一式を作るときに使います。書き出したいアートボードとスライスにチェックを入れ、PNG、JPEG、WebP、SVG を任意に組み合わせてチェックを入れ、倍率を 1x, 2x, 3x のようなリストで入力します。チェックを入れた各ページが、チェックを入れた各形式で、各倍率ごとに書き出されるので、1 回の実行でファイル一式を作成できます。SVG には固定のサイズがないため、ベクター出力では倍率は無視されます。ブラウザーが対応していればフォルダーを選び、すべてのファイルがそこに書き込まれます。対応していない場合は、ファイルが個別にダウンロードされます。

スライス

スライスは、カンバス上の長方形の範囲を指定して個別に書き出すためのもので、1 つのアートボードから複数の部分を切り出せます。オブジェクト > スライスから作成します。作成は選択範囲をスライスにし、ガイドから作成はアートボードをガイドに沿って分割し、選択範囲から作成は選択したオブジェクトごとに 1 つのスライスを作ります。スライスオプション…ではスライスの名前、形式、倍率を設定し、解除は選択したスライスを削除し、すべてを削除はすべてのスライスを消去します。スライスツール（⇧K）で手描きすることもできます。スライスは、スクリーン用に書き出しのリストにアートボードと並んで表示されます。

アセットパネル

アセットパネル（ウィンドウメニュー）は、アートボード全体ではなく、個々のアートワークを書き出します。アイコンセットやコンポーネントシートを作るのに適しています。アートワークを選択して選択範囲を追加を押すとリストに追加されるので、各項目の名前を変更します。名前がファイル名になります。形式（PNG、JPEG、WebP、SVG）と倍率を一度選び、書き出しを押すと、すべてのアセットがすべての組み合わせで書き出されます。各アセットは、それぞれの境界で切り抜かれて個別にレンダリングされます。

プリント

ファイル > プリント…（⌘P）は、アクティブなアートボードをブラウザーのプリントダイアログに送ります。ページはアートボードの縦横比に合わせて横向きまたは縦向きに設定され、12 mm の余白の内側にアートワークが収められます。先にファイル > ドキュメント設定…（⌥⌘P）でアートボードのサイズを設定しておいてください。
