Tre strumenti in Scissor fanno il lavoro ripetitivo per te: Azioni registrano una sequenza di comandi e la riproducono, Variabili sostituiscono testo e visibilità da una tabella di dati così un design diventa molti, e Script guidano l'intero editor da JavaScript. Nessuno di essi ha bisogno di un account o di un server: come il resto di Scissor funzionano sulla tua macchina.

Azioni: registra una volta, riproduci ovunque

Il pannello Azioni (Finestra › Azioni) registra ciò che fai e lo riproduce su una nuova selezione. Premi Registra, esegui i comandi che vuoi catturare — allinea, offset, aggiungi un'ombra, qualunque sia la sequenza — poi premi Stop e dai un nome all'azione. Entra nell'elenco, mostrando quanti passaggi contiene.

Fai clic su un'azione per riprodurla su ciò che è selezionato ora; ⌥-clic su una per eliminarla. Poiché un'azione è solo un elenco di comandi, ripete una routine esatta su molti oggetti senza che tu debba cliccarla ogni volta.

Variabili: un design, molte versioni

Il pannello Variabili (Finestra › Variabili) trasforma un design fisso in un template guidato da dati. Due cose su un oggetto possono essere rese dinamiche:

Rendi testo dinamico
Lega le parole di un oggetto di testo a una variabile, così diversi set di dati possono mettere testo diverso nello stesso posto.
Rendi visibilità dinamica
Lega se un oggetto si mostra, così un set può attivare o disattivare parti del design.

Scollega rende di nuovo fisso un oggetto collegato.

Set di dati

Un set di dati è una riga di valori per quelle variabili — un badge, una scheda, un frame. Cattura salva i valori correnti come nuovo set; le frecce passano da un set al successivo e il design si aggiusta per corrispondere. Importa CSV… legge un intero batch in una volta — una colonna per variabile, una riga per set — ed Esporta CSV scrive i set di nuovo fuori per modificarli in un foglio di calcolo.

Esportare ogni set in una volta

Esporta set di dati… rende la tavola attiva una volta per ogni set di dati e li scrive tutti in un'unica passata, come PNG, JPEG, WebP o SVG. Un foglio di badge, un set di banner localizzati o una serie di card social arrivano come un ordinato batch di file, ciascuno con i suoi dati compilati.

Script: guida Scissor da JavaScript

Per qualsiasi cosa un menu non può esprimere, uno script può. File › Script › Console script… apre un editor dove scrivi JavaScript e lo esegui sul documento aperto; Altro script… (⌘F12) esegue un file .js dal disco. Uno script viene eseguito in un Web Worker, lontano dalla pagina, così non può toccare l'interfaccia né i tuoi file se non attraverso l'oggetto scissor che gli viene dato — ogni chiamata viene eseguita sul motore e risposta indietro.

L'oggetto scissor copre il terreno comune:

Crea forme e testo
scissor.rect, roundedRect, ellipse, polygon, star, path e text disegnano lavoro; ciascuno prende una posizione e una dimensione e un oggetto opzioni per fill, stroke e strokeWidth (i colori sono qualsiasi colore CSS).
Leggi il documento
await scissor.document() restituisce l'app, la selezione, i livelli e le tavole da stampa come li vedono i pannelli; scissor.selection() restituisce solo ciò che è selezionato.
Agisci su di esso
scissor.select, group e undo, e scissor.run(command) per qualsiasi comando del motore — gli stessi comandi che i menu inviano.
Parla indietro
scissor.log stampa nella console; scissor.alert mostra un messaggio.

Un breve esempio — un anello di puntini colori e una didascalia:

const doc = await scissor.document();
scissor.log('Tavole:', doc.artboards.length);
for (let i = 0; i < 12; i++) {
  const a = (i / 12) * Math.PI * 2;
  await scissor.ellipse(300 + Math.cos(a) * 120, 260 + Math.sin(a) * 120, 36, 36,
    { fill: `hsl(${i * 30} 80% 60%)` });
}
await scissor.text(230, 270, 'Ciao, Scissor', { size: 24 });

La Console script conserva l'ultimo codice che hai eseguito, così uno script che funziona è lì quando torni ad esso.
