Три засоби в Scissor виконують повторювану роботу за вас: Операції записують послідовність команд і відтворюють її, Змінні підставляють текст і видимість із таблиці даних, тож один дизайн перетворюється на багато, а Скрипти керують усім редактором із JavaScript. Жоден із них не потребує облікового запису чи сервера — як і решта Scissor, вони працюють на вашому комп’ютері.

Операції: запишіть один раз, відтворюйте будь-де

Панель Операції (Вікно › Операції) записує ваші дії й відтворює їх на новому виділенні. Натисніть Запис, виконайте команди, які хочете зберегти, — вирівнювання, зміщення, додавання тіні, будь-яку послідовність, — потім натисніть Стоп і дайте операції назву. Вона з’явиться в списку разом із кількістю кроків, які містить.

Клацніть операцію, щоб відтворити її на тому, що зараз виділено; клацніть із ⌥, щоб її видалити. Оскільки операція — це просто список команд, вона точно повторює ту саму послідовність на багатьох об’єктах, і вам не доводиться щоразу проклацувати її вручну.

Змінні: один дизайн, багато версій

Панель Змінні (Вікно › Змінні) перетворює незмінний дизайн на шаблон, що керується даними. Динамічними можна зробити дві властивості об’єкта:

Зробити текст динамічним
Прив’язує слова текстового об’єкта до змінної, тож різні набори даних можуть підставляти різний текст в одне й те саме місце.
Зробити видимість динамічною
Прив’язує те, чи показано об’єкт, тож набір може вмикати або вимикати частини дизайну.

Відв’язати знову робить прив’язаний об’єкт незмінним.

Набори даних

Набір даних — це один рядок значень цих змінних: один бейдж, одна картка, один кадр. Захопити зберігає поточні значення як новий набір; стрілки переходять від одного набору до наступного, і дизайн оновлюється відповідно. Імпорт CSV… зчитує цілу партію одразу — один стовпець на змінну, один рядок на набір, — а Експортувати CSV записує набори назад у файл, щоб редагувати їх в електронній таблиці.

Експорт усіх наборів одразу

Експортувати набори даних… відображає активну монтажну область по одному разу для кожного набору даних і записує їх усі за один прохід у форматі PNG, JPEG, WebP або SVG. Аркуш бейджів з іменами, набір локалізованих банерів чи серія карток для соцмереж виходять акуратною партією файлів, кожен зі своїми даними.

Скрипти: керуйте Scissor із JavaScript

Те, чого не можна виразити через меню, може зробити скрипт. Файл › Скрипти › Консоль скриптів… відкриває редактор, де ви пишете JavaScript і запускаєте його для відкритого документа; Інший скрипт… (⌘F12) запускає файл .js із диска. Скрипт виконується у Web Worker, окремо від сторінки, тож він не може торкатися інтерфейсу чи ваших файлів інакше, ніж через наданий йому об’єкт scissor: кожен виклик виконується рушієм, і той надсилає відповідь.

Об’єкт scissor охоплює основні можливості:

Створення фігур і тексту
scissor.rect, roundedRect, ellipse, polygon, star, path і text малюють ілюстрацію; кожен приймає положення й розмір, а також об’єкт параметрів для fill, stroke і strokeWidth (кольори можна задавати будь-яким кольором CSS).
Читання документа
await scissor.document() повертає застосунок, виділення, шари й монтажні області так, як їх бачать панелі; scissor.selection() повертає лише виділене.
Дії з ним
scissor.select, group і undo, а також scissor.run(command) для будь-якої команди рушія — тих самих команд, які надсилають меню.
Зворотний зв’язок
scissor.log виводить у консоль; scissor.alert показує повідомлення.

Короткий приклад — коло з кольорових крапок і підпис:

const doc = await scissor.document();
scissor.log('Boards:', doc.artboards.length);
for (let i = 0; i < 12; i++) {
  const a = (i / 12) * Math.PI * 2;
  await scissor.ellipse(300 + Math.cos(a) * 120, 260 + Math.sin(a) * 120, 36, 36,
    { fill: `hsl(${i * 30} 80% 60%)` });
}
await scissor.text(230, 270, 'Hello, Scissor', { size: 24 });

Консоль скриптів зберігає останній запущений код, тож робочий скрипт чекатиме на вас, коли ви повернетеся.
