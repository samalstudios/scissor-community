A Scissor document can hold painted pixels alongside its drawn paths and type, so a single file can carry a soft brushed texture, a photograph and a crisp logo together. This page covers what a pixel layer is, how to paint on one, and how it behaves as an object in the document.

Pixels versus vector artwork

A Scissor document holds two kinds of artwork side by side. Paths and type are drawn: they stay sharp at any size because they are described by their shape, and Scissor redraws them whenever you zoom or scale. A pixel layer is painted: it is a grid of coloured dots, like a photograph or a brush painting, and enlarging it makes those dots bigger rather than adding detail. One document can hold as many of each as you like, in any order, and they stack in the Layers panel together.

Reach for a pixel layer when a shape alone will not do: a hand-painted shadow, a rough texture behind clean type, a splash of colour that does not need to be an editable path, or retouching over a placed photograph. Keep logos, diagrams and anything you will resize later as vectors, and use pixels for the parts that want the feel of paint.

A placed photograph is a related but separate thing. File > Place… (⇧⌘P) brings an existing image into the document as an embedded picture; a pixel layer is a surface you paint on from scratch inside Scissor. Both are made of pixels and both can be sampled with the eyedropper, but only a pixel layer takes brush strokes.

Making a pixel layer

Object > Pixel Layer > New Pixel Layer adds an empty surface covering the active board. You do not have to make one first, though: pick the Brush and paint, and Scissor creates the layer for you the moment the first stroke lands. Either way the layer maps onto the board, so the pixels line up with the artboard whatever resolution they were made at.

That resolution comes from the Raster Effects setting in File > Document Setup… (⌥⌘P): Screen (72 ppi), Medium (150 ppi) or High (300 ppi). A higher setting gives a new pixel layer more dots per point, so brushwork stays smooth when the piece is printed or viewed large. Set it before you make the layer, since the pixel count is fixed when the surface is created.

In the modern shell you can also add a layer from the tool options bar: with the Brush or Pixel Eraser active, a New pixel layer button sits at the end of the bar.

Placing a picture makes a pixel layer too. Drop an image onto the canvas, use File > Place…, or paste one from the clipboard, and it comes in as an editable pixel layer at its own size rather than a locked picture — so you can paint on it, mask it, adjust and filter it straight away. Opening an image with File > Open makes a new document one board the size of the picture, filled by the pixel layer. Very large photos are scaled down to fit the pixel budget. An SVG stays vector — its paths remain editable — so only bitmap images (PNG, JPEG, GIF, WebP, and the like) become pixel layers.

A layered .psd file comes in richer: opening one rebuilds its stack as separate pixel layers, keeping each layer's mask, and bringing type, shapes and layer effects across so the file lands close to how it looked where it was made rather than as one flat picture. It is the fullest way into pixel work, and everything on this page then applies to the layers that arrive.

Painting

The Brush and the Pixel Eraser

Two tools work on pixel layers.

ToolWhere it livesWhat it does
Brush ToolShares a slot with the Paintbrush (B) and Fill Brush (⇧B)Lays down colour that becomes part of the picture
Pixel Eraser ToolShares a slot with the Eraser (⇧E), Scissors and KnifeRubs paint away so whatever sits below shows through

To reach either, press and hold the visible tool in the toolbar, or right-click it, and choose the pixel tool from the list. Do not confuse them with their vector neighbours: the Paintbrush draws a path you can reshape afterwards, while the Brush paints pixels that cannot be re-pointed. Both pixel tools show a ring on the canvas at the size they will paint, and both use a crosshair pointer.

Drag to paint or erase. The mark follows the pointer without gaps however fast you move, because Scissor lays a run of round dabs along the stroke and keeps them evenly spaced even when the pointer jumps. The Pixel Eraser takes alpha away rather than painting over, so what it clears goes fully transparent; a tile erased back to nothing is dropped, so erasing does not leave weight behind.

Painting in the fill colour

The Brush paints in the current fill colour. Set it the way you set any fill: the Colour panel, a swatch, or, when the Brush is active in the modern shell, the Colour chip in the tool options bar. If the fill is empty the Brush falls back to the stroke colour, and to black if there is no colour at all. Pick a colour straight off a pixel layer with the Eyedropper when you want to match paint that is already down.

Size, hardness and flow

When the Brush or Pixel Eraser is active, the tool options bar carries the settings that shape the mark. They also live in your preferences, so they carry from one session to the next.

Size
The brush diameter, from 1 up to 2500 pixels. Press [ to make the brush smaller and ] to make it larger; each press changes the size by a fifth, so the step grows with the brush. The ring on the canvas shows the current size.
Hardness
Where the edge starts to fade, as a percentage. At 100% the edge is crisp; lower it and the dab softens towards its rim with a smooth falloff and no visible ring. Use a soft brush for shadows and glows, a hard one for solid shapes.
Flow
How much paint each dab puts down, for the Brush only. Below 100% the colour builds up gradually as you pass over an area again, which suits shading and slow blends. The Pixel Eraser has no flow control.

Dodging, burning and sponging

Three retouch brushes work into the pixels that are already there rather than laying down a colour, sharing one slot in the toolbar. They paint like the Brush — the same size, hardness and canvas ring — and build up as you pass over an area again, so a light touch is gradual and a firm one is quick.

Dodge
Lightens wherever you paint, lifting shadows and adding highlights.
Burn
Darkens wherever you paint, deepening shadows and edges.
Sponge
Lifts saturation, making colours richer the more you go over them.

Each leaves transparent pixels untouched, stays inside a selection when one is set, and the whole stroke undoes in a single step.

Bucket, shapes and gradients

Painting is not only the Brush. On a pixel layer three more tools lay down colour: the Paint Bucket floods a contiguous area of similar colour from where you click; the shape tools stamp a rectangle, ellipse, star or polygon straight into the pixels instead of drawing a path; and the Gradient tool paints a linear or radial blend across the surface. Each respects the current selection, so you can confine a fill or a gradient to a chosen region.

Selecting pixels

A pixel selection — a marquee — limits every paint and edit to the region inside it, the way a stencil does. Three tools make one, sharing the pixel-selection slot: the Rectangular and Elliptical Marquee, and a freehand Lasso Marquee you trace by hand. Drag to draw a selection; a plain drag replaces the current one.

The Auto-Select selects by colour instead of by shape: click a pixel layer and it takes the connected patch of colour around where you clicked, tracing a marching-ants outline around it — handy for lifting a flat background or one coloured area. How near a colour must be to be taken is the Tolerance on the Auto-Select options, the same setting it uses on vector objects; raise it to gather more, lower it to keep to a close match. Holes in the patch are left out of the selection.

Selections combine, so a shape can be built from several strokes or clicks: hold ⇧ to add to the selection, ⌥ to subtract, and both together to keep only the overlap — the marquees and the Auto-Select all combine the same way. Select > All (⌘A) selects every pixel, Select > Inverse flips the marquee, and Deselect — ⌘D on a pixel layer — drops it. A marching-ants outline shows the selection on the canvas.

Moving, cutting and copying pixels

With a selection set, the Selection tool moves the pixels inside it: drag from within the marquee and the selected paint lifts and travels, clearing where it was and carrying the marquee along. Hold ⌥ while dragging to leave the original in place and move a copy.

The transform tools work on the selection too. With a marquee set, the bounding box of the Selection tool and the Free Transform Tool (E) wrap the marquee, not the whole layer, so you can scale, rotate or move just that part of the picture; Object > Transform and the arrow keys act on it the same way. The lifted pixels float above the layer while you work, so you can drag them again and again without losing any detail. Press Enter, pick another tool, or make a new selection to set them down, which is a single step to undo, or press Escape to put everything back where it was. A move by whole pixels keeps them exactly as they were; scaling or turning resamples them once, when they are set down.

The Free Transform Tool's Free Distort and Perspective Distort work on pixels as well, on a marquee or on a whole layer: drag a corner of the box (or hold ⌘ while dragging one in Free Transform mode) to pull the picture out of true, for example to fit a photo onto a screen or a sign seen at an angle. While you drag, Scissor shows a quick preview sized to the screen, so it stays smooth even on a large photo; the pixels themselves are pulled once, at full resolution, when you press Enter or move on, and the marquee follows the new shape.

Copy (⌘C) and Cut (⌘X) work on the pixels inside a marquee: copying leaves the layer as it is, cutting takes the pixels out. Paste (⌘V) puts them on a new pixel layer just above the one they came from, in exactly the same place, ready to move or transform on their own. The same commands are in Create > Pixel Layer, and the selection also drives the surface commands: Fill with Fill Colour fills only the selected region, Clear and Delete erase it, and with no selection each acts on the whole layer.

Adjustments

The Object > Pixel Layer > Adjustments submenu retouches the colour of a pixel layer, confined to the selection when one is set. Each opens a dialog that previews on the canvas as you drag.

Brightness / Contrast, Levels
Set the overall lightness and contrast, or remap the black point, white point and gamma for finer tonal control.
Hue / Saturation, Vibrance
Shift the hue and lift or drop saturation across the board, or use Vibrance to boost the muted colours while leaving the already-vivid ones alone.
Colour Balance
Push the midtones towards cyan or red, magenta or green, yellow or blue.
Gradient Map
Recolour the layer by its brightness, mapping the shadows to one colour and the highlights to another.
Desaturate, Invert
Drop all colour to grey, or flip every colour to its opposite.
Threshold, Posterize
Reduce the image to pure black and white at a chosen level, or to a small number of tones per channel.

Filters

The Filters submenu reshapes the pixels themselves, again within the selection.

Gaussian Blur
Softens the layer by an even, adjustable amount.
Sharpen, Unsharp Mask
Crisp the detail — Unsharp Mask gives control over the radius, amount and a threshold that spares flat areas and fine noise.
Pixelate
Blocks the image into square tiles for a mosaic.
Add Noise
Scatters grain across the paint.
Find Edges, Emboss
Trace where the colour changes as bright lines on dark, or as a grey relief.

Filters > Effect Previews opens a grid of live thumbnails, each showing your layer with one adjustment or filter already applied, so you can pick by eye rather than by name. Clicking a thumbnail opens that effect's dialog to fine-tune it — or applies it straight away for the ones with nothing to set, like Desaturate, Invert, Find Edges and Emboss.

Fast, tile-based undo

A whole stroke undoes in one step, however long it was: press ⌘Z once and the last mark is gone, and ⇧⌘Z brings it back. If the first stroke had to create its layer, that layer goes back with the stroke rather than being left behind empty.

Behind the scenes a pixel layer is kept as a grid of small tiles, and a stroke only ever copies the tiles it actually touched. Undoing keeps whole document snapshots, but a stroke costs only its own tiles rather than the whole surface, so painting on a large layer stays quick and a long session of brushwork does not fill up memory. Flat areas of one colour are stored compactly, so a layer that is mostly a single colour takes almost no room.

Treating a pixel layer like any object

A pixel layer is an object in the document, so everything you already know applies. Select it, move it, and scale, rotate, reflect or shear it from Object > Transform, the bounding box or the Free Transform Tool. With no marquee, the box wraps the layer's painted pixels rather than its whole surface, and a transform works on those pixels: moving keeps them untouched, while scaling or turning is baked into the pixels when you press Enter, pick another tool or select something else, so the layer stays upright and the next brush stroke lands the right way up. Set its opacity and give it any of the sixteen blend modes from the Transparency panel to sit painted colour over the drawn artwork below. Clicking picks the layer only where it has paint, so a transparent corner lets you click straight through to whatever is underneath. Duplicate copies a pixel layer like any object — cheaply, since the copy shares its tiles until one of them is painted.

Object > Pixel Layer > Merge Down flattens a pixel layer onto the pixel layer directly beneath it and removes the top one, leaving a single layer with the two composited together. If the layers sit under different transforms — say one has been rotated — the top is resampled into the bottom's grid as it merges.

Two commands act on the whole surface at once:

Object > Pixel Layer > Fill with Fill Colour
Floods the entire surface with the current fill colour. Reach for it to lay a base coat before painting over it, or to flood a layer set behind other art.
Object > Pixel Layer > Clear
Empties the surface without removing the layer, so you can start the painting again while keeping the layer's place, transform, opacity and blend mode.

Both commands also appear under Effect > Pixel Layer.

Layer masks

A layer mask hides parts of a pixel layer without deleting them: the layer shows through where the mask is white and is hidden where it is black, with greys in between for partial transparency. Because nothing is erased, you can paint the mask back and forth as often as you like. The commands are under Object > Pixel Layer.

Add Layer Mask
Attaches a mask that reveals everything to start with, ready to paint on.
Add Layer Mask from Selection
Builds the mask from the current pixel selection: what is inside stays, what is outside is hidden. A quick way to cut a shape out of a photo non-destructively.
Edit Mask
Turns mask painting on and off. While it is on, the Brush, Eraser and Paint Bucket paint the mask instead of the layer: paint with black (or a dark colour) to hide, white to reveal, grey to fade. The brush uses the lightness of the current fill colour, so black hides and white shows.
Apply Layer Mask
Bakes the mask into the layer for good — the hidden pixels become transparent — and removes the mask.
Delete Layer Mask
Throws the mask away and shows the whole layer again, untouched.

A masked layer exports and saves with the mask already applied, and blends and transforms like any other layer.

Turning vector art into pixels: Rasterize

Object > Rasterize replaces the current selection with an embedded picture of itself, baking the paths, type and any effects into fixed pixels. Use this when you want a vector result to stop being editable, when an effect is easier to treat as a flat image, or to hand off a piece that should look the same everywhere without carrying its live construction. The result is an embedded image rather than a paintable pixel layer, so keep a copy of the original artwork if you may need to edit it again. View > Pixel Preview (⌥⌘Y) lets you check how vector art will land on the pixel grid before you commit.

Saving and exporting

.cut documents keep pixel layers with the rest of the artwork, packed so that flat areas take almost no room and reopen exactly as painted.

How pixel layers leave the document depends on the format:

PNG, JPEG and WebP
Flatten the whole document to pixels, so painted and drawn work merge into one bitmap. PNG can keep transparency; export at @2x for a sharper result.
SVG and PDF
Write the painted surface out as an embedded picture set among the vector art, so a document that mixes drawn and painted work travels as one file with its shapes still crisp.

Because raster and vector live in the same document and export together, you can build a piece the natural way: clean shapes and type as vectors, and the parts that want the feel of paint, a soft glow, a textured wash, a retouched photograph, as pixel layers stacked among them.
