Drie gereedschappen in Scissor doen het repetitieve werk voor u: Acties nemen een reeks commando's op en spelen het af, Variabelen wisselen tekst en zichtbaarheid uit een tabel met gegevens zodat één ontwerp veel wordt, en Scripts besturen de hele editor vanuit JavaScript. Geen ervan heeft een account of een server nodig — net als de rest van Scissor draaien ze op uw eigen machine.

Acties: één keer opnemen, overal afspelen

Het Acties-paneel (Venster › Acties) neemt op wat u doet en speelt het op een nieuwe selectie af. Druk op Opnemen, voer de commando's uit die u wilt vastleggen — uitlijnen, compenseren, een schaduw toevoegen, wat de reeks ook is — en druk dan op Stop en geef de actie een naam. Het treedt de lijst bij, tonend hoeveel stappen het bevat.

Klik op een actie om het op wat nu is geselecteerd af te spelen; ⌥-klik eréén om het te verwijderen. Omdat een actie slechts een lijst van commando's is, herhaalt het een exacte routine over veel objecten zonder dat u er elke keer doorheen hoeft te klikken.

Variabelen: één ontwerp, veel versies

Het Variabelen-paneel (Venster › Variabelen) verandert een vast ontwerp in een sjabloon dat door gegevens wordt aangestuurd. Twee dingen op een object kunnen dynamisch worden gemaakt:

Tekst dynamisch maken
Verbindt de woorden van een tekstobject aan een variabele, zodat verschillende gegevenssets verschillende tekst op dezelfde plaats kunnen zetten.
Zichtbaarheid dynamisch maken
Verbindt of een object toont, zodat een set delen van het ontwerp aan of uit kan zetten.

Ontbinden maakt een gebonden object vast weer.

Gegevenssets

Een gegevensset is één rij waarden voor die variabelen — één badge, één kaart, één frame. Vastleggen slaat de huidige waarden op als een nieuwe set; de pijlen stappen van de ene set naar de volgende en het ontwerp werkt bij om overeen te komen. CSV importeren… leest een hele batch tegelijk — één kolom per variabele, één rij per set — en CSV exporteren schrijft de sets terug uit om in een spreadsheet te bewerken.

Elke set tegelijk exporteren

Gegevenssets exporteren… rendert het actieve bord één keer voor elke gegevensset en schrijft ze allemaal in één keer uit, als PNG, JPEG, WebP of SVG. Een vel naambadges, een set gelokaliseerde banners of een reeks sociale kaarten komt eruit als een netje batch van bestanden, elk met zijn eigen gegevens ingevuld.

Scripts: Scissor besturen vanuit JavaScript

Voor alles wat een menu niet kan uitdrukken, kan een script het. Bestand › Scripts › Scriptconsole… opent een editor waarin u JavaScript schrijft en het tegen het geopende document uitvoert; Ander script… (⌘F12) voert een .js-bestand vanaf de schijf uit. Een script draait in een Web Worker, weg van de pagina, dus het kan de interface of uw bestanden niet aanraken behalve door het scissor-object dat het krijgt — elk bevel wordt op de engine uitgevoerd en beantwoord.

Het scissor-object bestekt het gemeenschappelijke terrein:

Vormen en tekst maken
scissor.rect, roundedRect, ellipse, polygon, star, path en text tekenen werk; elk neemt een positie en grootte en een optieobject voor fill, stroke en strokeWidth (kleuren zijn elke CSS-kleur).
Het document lezen
await scissor.document() geeft de app, selectie, laag en artboards terug zoals de panelen ze zien; scissor.selection() geeft alleen wat is geselecteerd terug.
Erop werken
scissor.select, group en undo, en scissor.run(command) voor elk engine-commando überhaupt — dezelfde commando's die de menu's sturen.
Terugpraten
scissor.log drukt naar de console; scissor.alert toont een bericht.

Een kort voorbeeld — een ring van gekleurde stippen en een bijschrift:

const doc = await scissor.document();
scissor.log('Borden:', doc.artboards.length);
for (let i = 0; i < 12; i++) {
  const a = (i / 12) * Math.PI * 2;
  await scissor.ellipse(300 + Math.cos(a) * 120, 260 + Math.sin(a) * 120, 36, 36,
    { fill: `hsl(${i * 30} 80% 60%)` });
}
await scissor.text(230, 270, 'Hallo, Scissor', { size: 24 });

Het Scriptconsole bewaart de laatste code die u heeft uitgevoerd, dus een werkend script is er wanneer u erop terugkomt.
