Tres eines a Scissor fan la feina repetitiva per a vostè: Accions enregistren una seqüència de comandaments i la reprodueixen, Variables substitueixen text i visibilitat des d'una taula de dades de manera que un disseny es converteix en molts, i Scripts guien tot l'editor des de JavaScript. Cap d'elles necessita un compte o un servidor: com la resta de Scissor funcionen a la vostra màquina.

Accions: enregistra una vegada, reprodueix arreu

El panell Accions (Finestra › Accions) enregistra el que feu i el reprodueix sobre una nova selecció. Premeu Enregistra, executeu els comandaments que voleu capturar — alínia, desplaçament, afegeix una ombra, qualsevol que sigui la seqüència — després premeu Atura i doneu un nom a l'acció. S'uneix a la llista, mostrant quants passos conté.

Feu clic a una acció per reproduir-la sobre allò que està seleccionat ara; ⌥-clic a una per eliminar-la. Com que una acció és només una llista de comandaments, repeteix una rutina exacta sobre molts objectes sense que hagi de clicar-la cada vegada.

Variables: un disseny, moltes versions

El panell Variables (Finestra › Variables) converteix un disseny fix en una plantilla guiada per dades. Dues coses sobre un objecte es poden fer dinàmiques:

Fes text dinàmic
Lliga les paraules d'un objecte de text a una variable, de manera que diferents conjunts de dades puguin posar text diferent al mateix lloc.
Fes visibilitat dinàmica
Lliga si un objecte es mostra, de manera que un conjunt pugui activar o desactivar parts del disseny.

Deslliga torna a fer fix un objecte lligat.

Conjunts de dades

Un conjunt de dades és una fila de valors per a aquelles variables — una insígnia, una targeta, un marc. Captura desa els valors actuals com a nou conjunt; les fletxes passen d'un conjunt al següent i el disseny s'actualitza per coincidir. Importa CSV… llegeix un lot sencer d'un cop — una columna per variable, una fila per conjunt — i Exporta CSV escriu els conjunts de nou fora per editar-los en un full de càlcul.

Exportar cada conjunt d'un cop

Exporta conjunts de dades… renderitza la taula activa una vegada per cada conjunt de dades i els escriu tots en una sola passada, com a PNG, JPEG, WebP o SVG. Una fulla d'insígnies, un conjunt de bàners localitzats o una sèrie de targetes socials surten com un lot ordenat de fitxers, cadascun amb les seves dades omplertes.

Scripts: guia Scissor des de JavaScript

Per a qualsevol cosa que un menu no pot expressar, un script pot. Fitxer › Scripts › Consola de scripts… obre un editor on escriviu JavaScript i el executeu sobre el document obert; Altre script… (⌘F12) executa un fitxer .js del disc. Un script s'executa en un Web Worker, lluny de la pàgina, de manera que no pot tocar la interfície ni els vostres fitxers excepte a través de l'objecte scissor que se li dóna — cada trucada s'executa al motor i es respon enrere.

L'objecte scissor cobreix el terreny comú:

Crea formes i text
scissor.rect, roundedRect, ellipse, polygon, star, path i text dibuixen feina; cadascun pren una posició i una mida i un objecte d'opcions per a fill, stroke i strokeWidth (els colors són qualsevol color CSS).
Llegeix el document
await scissor.document() retorna l'app, la selecció, les capes i les taules d'art com les veuen els panells; scissor.selection() retorna només allò que està seleccionat.
Actua sobre ell
scissor.select, group i undo, i scissor.run(command) per a qualsevol comandament del motor — els mateixos comandaments que els menús envien.
Parla enrere
scissor.log imprimeix a la consola; scissor.alert mostra un missatge.

Un breu exemple — un anell de punts de colors i una llegenda:

const doc = await scissor.document();
scissor.log('Taules:', doc.artboards.length);
for (let i = 0; i < 12; i++) {
  const a = (i / 12) * Math.PI * 2;
  await scissor.ellipse(300 + Math.cos(a) * 120, 260 + Math.sin(a) * 120, 36, 36,
    { fill: `hsl(${i * 30} 80% 60%)` });
}
await scissor.text(230, 270, 'Hola, Scissor', { size: 24 });

La Consola de scripts conserva el darrer codi que heu executat, de manera que un script que funciona és allà quan hi torneu.
