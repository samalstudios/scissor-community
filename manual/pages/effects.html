An effect changes how an object looks without changing the object itself. The path, the group or the piece of type stays exactly as you drew it, and the effect is recomputed on top every time you move a point or edit a value. Effects stack in the Paint Stack panel, so you can pile several on one object, reorder them and take any of them off again.

Live effects and the appearance stack

Every effect in Scissor is live and non-destructive. It sits above the object's fills and strokes in the Appearance panel (⇧F6) and runs over the whole object each time the artwork or the effect changes. Because the original path is untouched underneath, you can keep editing anchor points, swap the fill colour or retype the words, and the effect follows along. Reach for an effect whenever you want a look, a shadow, a bend, a rounded corner, that you might change your mind about later, rather than committing to it by hand.

Order matters

Effects run from the bottom of the stack upwards, and the panel lists them top first, above the fills and strokes. The order changes the result: a blur under a drop shadow softens the shape before the shadow is cast, while the same two the other way round casts a sharp shadow and then blurs the whole lot. If an effect is not doing what you expect, its position in the stack is the first thing to check.

Adding, editing and removing effects

From the Effect menu

Select an object, then pick an effect from the Effect menu. Items that open a dialog show a Preview as you change their values, so you can judge the result on the canvas before you commit; the whole edit lands as a single step in the history rather than one step per keystroke. A short version of the menu (Drop Shadow, Outer Glow and Gaussian Blur, plus Clear Effects) also sits in the canvas right-click menu under Effect.

In the Paint Stack panel

Each effect on the selected object gets its own row in the Paint Stack panel, marked with an fx badge. Click the effect's name to reopen its options and change them. Click the cross at the end of the row to remove that one effect. To strip every effect from the selection at once, use Effect › Clear Effects.

In the Effects panels

The Window › Effects group gathers the effects into one panel for each part of the Effect menu: Stylize, Blur, Distort & Transform, Path, Combine Shapes and Warp, with the 3D panel alongside. Each panel lists that group's effects with a switch to turn one on or off and its settings just below, all edited live on the selection. It is a quicker way to try an effect and adjust its values than opening a dialog each time. Turning a switch off takes that effect back off the object. When an object carries more than one effect of the same kind, the panel edits the first of them and the Paint Stack panel still shows the whole stack.

Blur

Effect › Blur › Gaussian Blur softens the whole object by a Radius you set in pixels. Because it stays live, you can raise or lower the radius at any time. Use it for a soft, out-of-focus background, or as a quick soft shadow shape on its own.

Combine Shapes

The Effect › Combine Shapes submenu combines the shapes inside a group with a shape mode, but keeps them as separate, editable paths underneath. Apply it to a group and the combined result is what you see, while each member can still be moved or recoloured. Use it to try a combination without committing to it the way the Combine Shapes panel would.

Warp

Effect › Warp bends the object along one of a set of preset shapes, and stays live so you can keep editing the artwork underneath. Use it to curve a headline into an arch, wave a banner, or push a flat block into a bulge, without giving up the ability to change the words or the colours.

The menu offers ten styles directly (Arc, Arch, Bulge, Flag, Wave, Fish, Rise, Fisheye, Inflate and Squeeze). Warp Options… opens the full set, which adds Arc Lower, Arc Upper, Shell Lower and Shell Upper, and lets you dial in the amount:

Bend
How strongly the shape bends, from -100% to 100%.
Horizontal
Leans the bend to one side, from -100% to 100%.
Vertical
Tips the bend up or down, from -100% to 100%.

The same warp styles can be applied as a reshaping envelope instead, which changes the path itself rather than staying live: see Shape Warp. The Warp tool and the other liquify tools reshape by dragging on the canvas and are covered under the tools reference.

3D and Materials

Effect › 3D and Materials turns a flat shape into a solid: a plane, an extrude and bevel, a revolve or an inflate. Like the others it is a live effect, so the flat path stays there to edit and the solid rebuilds when you change it. The depth, bevel, rotation, lighting and surface are set in the 3D and Materials panel. Because it has more controls than a single dialog, 3D has its own page: see 3D.

Turning effects into artwork

An effect stays live for as long as you want it. When the look is settled and you need the result as plain, editable paths, for example to hand the file on or to reshape the effect's output by hand, choose Object › Expand Appearance. It bakes the whole appearance stack, effects included, down into ordinary artwork. This cannot be edited as an effect afterwards, so expand only once you are sure. To take effects off without baking anything, remove them one at a time in the Paint Stack panel or clear them all with Effect › Clear Effects.

The Effect menu also lists Rasterize, which is not a live effect: it converts the selection into pixels there and then. Painting and pixel layers are covered on the Pixel layers page.
