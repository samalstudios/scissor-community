Opening, saving, placing, exporting and printing all happen on your own computer. This page covers the native .cut document, the formats Scissor can read and write, and how artwork gets in and out.

Everything stays on your device

Scissor has no server and no account. A file you open is read in the browser, on your own machine, and a file you export is written straight back to your disk. Nothing is uploaded, and artwork never leaves the computer unless you send it somewhere yourself. That also means there is no cloud copy to fall back on, so save your work like any other desktop document.

In the shortcuts below, ⌘ is Ctrl on Windows and Linux, and ⌥ is Alt.

The .cut document

Scissor's own format is .cut, a versioned JSON file holding the whole node tree: every layer, group, path, live shape, piece of type, placed picture, gradient, effect and artboard, exactly as you left them. It is the only format that preserves everything Scissor can do, so it is what you save while a piece is still being worked on. Reach for an export format only when the artwork needs to travel to another program or to the web.

Saving your work

Use File > Save (⌘S) to write the document, Save As… (⇧⌘S) to write it under a new name, and Save a Copy… (⌥⌘S) to write a snapshot to one side while you carry on in the original.

Where the browser supports it, Scissor keeps a handle on the file you picked, so later saves go back to the same place with no dialog, the way a desktop application would. Where it does not, each save arrives as a download of a fresh .cut file. If a saved file has since been moved, or its permission withdrawn, Scissor falls back to asking you where to put it again.

Starting and closing documents

File > New… (⌥⌘N) opens a blank document from the New Document dialog, where you set its size and how many artboards it starts with. File > Open… (⌘O) reads existing files, and can take several at once. Close the active document with File > Close (⌥⌘W).

Opening other formats

File > Open… (⌘O) reads more than Scissor's own documents. You can select several files in one go, or drag them onto the canvas. What comes through depends on the format.

SVG (.svg)
Read in depth. Paths and the basic shapes (rectangle, circle, ellipse, line, polyline, polygon), groups, nested svg, use and symbol, and the full set of transforms come across. So do presentation attributes, inline styles and simple <style> rules (by tag, class or id), linear and radial gradients, clipping paths, basic text including type set along a path, and images whether embedded or linked. Colours are read as hex, rgb, hsl or a CSS colour name, and lengths in px, points, picas, inches, millimetres, centimetres, em or ex. Axis-aligned rectangles, circles and ellipses arrive as live shapes, so they stay editable by their handles rather than becoming frozen outlines. An SVG that carries layers opens with those layers kept, names and all, and any that were hidden or locked stay hidden and locked. Pattern fills, masks, markers and filter effects are not brought across.
PDF, and PDF-based .ai
One artboard per page. Paths, colours, line style, clipping, form XObjects, text with its font and position, and pictures (including JPEG, indexed images and stencil masks with their soft-mask alpha) all come through. Axial and radial shadings are read whether painted directly or through a pattern fill.
EPS (.eps, .epsf)
An EPS file is a PostScript program, so Scissor runs one. Paths, transforms, clipping, grey, RGB, CMYK, HSB and spot colours, line width, caps, joins and dashes, compound paths with their holes, and text with its font all come through, and the %%BoundingBox comment becomes the artboard (a %%HiResBoundingBox wins when the file gives one). The common shorthand operators are built in, so files that rely on them read without running their own prolog, and the binary wrapper a DOS EPS carries is unwrapped first. Raster images embedded in an EPS are skipped.
PSD (.psd)
Pixel layers become editable pixel layers inside their groups, keeping their names, opacity, blend mode and hidden state. Layer masks are baked into the alpha; vector masks and the paths saved with the file arrive as editable paths; type layers as editable text. The layer styles that draw (drop shadows, inner shadows and glows) come through as live effects.

Raster pictures (.png, .jpg, .gif, .webp, .bmp, .avif) can be opened too. Opened from the file dialog, a picture becomes its own document on one artboard sized to the image; dropped onto artwork you already have open, it is placed into that document instead.

A design program that keeps a closed, unpublished format of its own leaves those files unreadable to everyone else, so Scissor does not open them. Export SVG or PDF from that program instead, and Scissor reads both.

Why .ai is read but never written

A modern .ai file is a PDF, which is why one opens through the PDF importer. Writing .ai is another matter: the extension names another program's document, and a file claiming to be one while carrying Scissor's own structure would mislead whoever opened it next. Scissor writes .cut for its own work, and PDF or SVG when the artwork needs to travel.

Placing artwork

File > Place… (⇧⌘P) brings SVG and raster pictures (PNG, JPEG, GIF, WebP) into the document you already have open, rather than starting a new one. Use it to drop a logo, a photo or a piece of scanned line art into a layout in progress.

Placed SVG arrives as editable artwork: its shapes, paths and type land in the document as objects you can select and reshape, not as a flat picture. A raster image (PNG, JPEG, GIF, WebP) arrives as an editable pixel layer at its own size — paint on it, mask it, adjust and filter it straight away, and trace it with Vectorize. The pixels are held inside the document, so it never goes looking for a linked file that might move or go missing; a very large photo is scaled down to fit a single surface.

Dragging a file onto the canvas does the same as placing it, except that a .cut, PDF, .ai, .psd or EPS file opens as a document of its own. Pasting a picture from the clipboard places it as well. To turn live artwork into pixels once it is finished, use Object > Rasterize, which replaces the selection with a 2x image of itself.

Copy, cut and paste

Copy (⌘C) and cut (⌘X) put the selection on the clipboard, and paste (⌘V) drops it back near the centre of the view. Scissor keeps a full-fidelity copy of its own for round trips inside the app, and also writes the selection to the system clipboard as SVG, so you can paste artwork straight into another program.

Three variants control where a paste lands: Paste in Front (⌘F) and Paste in Back (⌘B) put it directly above or below the current selection in the stacking order, and Paste in Place (⇧⌘V) drops it at the same coordinates it was copied from. Because a copy also travels as SVG, text or artwork copied from elsewhere can be pasted in, and it arrives as editable objects.

Exporting

Exporting writes a copy of the artwork in a format made for sharing or the web, leaving the .cut document untouched. The File > Export submenu holds the single-file commands, and two other routes handle many files at once.

Single files

Export As SVG… writes the active artboard as SVG. The writer is thorough: live rectangles, circles and ellipses are written as real <rect>, <circle> and <ellipse> elements so they stay editable; linear and radial gradients, pattern fills, clipping and knockout groups, opacity, blend modes and isolation all come through; drop shadows, blurs, glows and feathers are written as SVG filters; and type stays as text, including type on a path, OpenType feature settings and a fill with an outline. Freeform gradients and gradient meshes, which no SVG gradient can describe, are written as many small coloured cells so any reader draws them correctly. Placed pictures and pixel layers are embedded as <image> elements.

Export As PNG…, Export As PNG @2x… and Export As PNG (Transparent)… render the active artboard as a PNG at one or two times its size, the last of them keeping a transparent background. Export As JPEG… and Export As WebP… write the other raster formats; JPEG has no transparency, so it always keeps the artboard background.

Export As PDF… writes the whole document as PDF, one page per artboard. This is an in-house writer that keeps vector paths, gradients, opacity, clipping, text and placed pictures with their transparency, so the result stays editable elsewhere rather than being a flattened picture of the artwork.

Export Selection… writes only the selected objects as SVG, cropped to what you picked. Reach for it when you want one icon or one shape out of a busy artboard.

Export for Screens

File > Export > Export for Screens… (⌥⌘E) writes many files in one pass, which is how you produce a set of assets at several sizes. Tick the artboards and slices you want, tick any combination of PNG, JPEG, WebP and SVG, and type the scales as a list such as 1x, 2x, 3x. Each ticked page is written in each ticked format at each scale, so one run can produce a whole spread of files. Vector output ignores scale, since SVG has no fixed size. Where the browser allows it you pick a folder and every file is written into it; otherwise the files arrive as separate downloads.

Slices

A slice marks out a rectangle of the canvas to export on its own, so you can cut several pieces from one artboard. Make them from Object > Slice: Make turns the selection into a slice, Create from Guides cuts the board along its guides, and Create from Selection makes one slice per selected object. Slice Options… sets a slice's name, format and scale, Release removes the selected slice, and Delete All clears them. You can also draw slices by hand with the Slice tool (⇧K). Slices appear alongside artboards in the Export for Screens list.

The Assets panel

The Assets panel (Window menu) exports individual pieces of artwork rather than whole boards, which suits building an icon set or a component sheet. Select some artwork and press Add Selection to add it to the list, then rename each entry: the name becomes the filename. Choose the formats (PNG, JPEG, WebP or SVG) and the scales once, then press Export to write every asset at every combination. Each asset is rendered on its own, cropped to its own bounds.

Printing

File > Print… (⌘P) sends the active artboard to the browser's own print dialog. The page is set landscape or portrait to match the artboard's proportions, with a 12 mm margin, and the artwork is fitted inside it. Set the artboard's size first in File > Document Setup… (⌥⌘P).
